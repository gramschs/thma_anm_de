11.3 Gedämpfte und erzwungene Schwingung

In Abschnitt 11.1 hat der ungedämpfte Federschwinger endlos weiter geschwungen. Das Phasenporträt zeigte eine geschlossene Ellipse, weil die mechanische Energie konstant bleibt. Ein reales Fahrzeug verhält sich anders: Der Stoßdämpfer entzieht der Schwingung Energie. Zu wenig Dämpfung, und die Karosserie wippt nach einer Bodenwelle lange weiter. Zu viel, und die Feder kann Unebenheiten kaum noch ausgleichen.

Dazu kommt die Straße selbst: Fahrbahnrillen regen das Fahrzeug nahezu periodisch an. Stimmt die Anregungsfrequenz mit der Eigenkreisfrequenz des Fahrwerks überein, wächst die Amplitude stark an. Aus dem einfachen Modell

m x¨+k x=0m\,\ddot{x} + k\,x = 0mx¨+kx=0

wird dann

m x¨+c x˙+k x=F0sin⁡(Ωt).m\,\ddot{x} + c\,\dot{x} + k\,x = F_0\sin(\Omega t).mx¨+cx˙+kx=F0​sin(Ωt).

Lernziele¶

Lernziele

  • Sie kennen den Dämpfungsgrad D=c / (2km)D = c\,/\,(2\sqrt{km})D=c/(2km​) und können die drei Fälle D<1D < 1D<1 (schwingend), D=1D = 1D=1 (aperiodischer Grenzfall) und D>1D > 1D>1 (Kriechfall) im Zeitsignal x(t)x(t)x(t) unterscheiden.

  • Sie können erklären, warum D=1D = 1D=1 die kürzeste Einschwingzeit ohne Überschwingen liefert.

  • Sie können eine erzwungene Schwingung mit solve_ivp lösen und die stationäre Amplitude aus dem eingeschwungenen Zustand als max(|x|) im letzten Zeitdrittel ablesen.

  • Sie erkennen Resonanz als das Amplitudenmaximum bei Ω≈ω0\Omega \approx \omega_0Ω≈ω0​ und können die Resonanzfrequenz erläutern.

Gedämpfter Schwinger: die drei Fälle¶

Welchen Unterschied macht die Dämpfung im Code? Die Differentialgleichung wird um den Term c x˙c\,\dot{x}cx˙ ergänzt. In f(t, y) ändert sich nur der zweite Rückgabewert: statt -(k/m)*y[0] steht jetzt (-k*y[0] - c*y[1]) / m. Alles andere bleibt identisch.

Für die Analyse der unterschiedlichen Dämpfungen definieren wir zunächst die kritische Dämpfung

ckrit=2k m .c_{\text{krit}} = 2 \sqrt{k \, m} \,.ckrit​=2km​.

Sie ist der Grenzwert, bei dem der Übergang vom schwingenden zum nicht schwingenden Verhalten stattfindet. Teilt man die tatsächliche Dämpfung ccc durch ckritc_{\text{krit}}ckrit​, erhält man den dimensionslosen Dämpfungsgrad

D=cckrit=c2k m .D = \frac{c}{c_{\text{krit}}} = \frac{c}{2 \sqrt{k \, m}} \,.D=ckrit​c​=2km​c​.

  • Für D<1D < 1D<1 schwingt das System,

  • für D=1D = 1D=1 liegt der sogenannte aperiodische Grenzfall vor (schnellste Rückkehr ohne Überschwingen) und

  • für D>1D > 1D>1 nähert sich die Bewegung ohne Schwingung langsam der Ruhelage (Kriechfall).

Im Code wählen wir DDD vor und berechnen daraus ccc über c=D⋅ckritc = D \cdot c_{\text{krit}}c=D⋅ckrit​. Wir betrachten nun die Schwingung, die sich bei verschiedenen Dämpfungsgraden ergibt, und definieren dazu die rechte Seite der Differentialgleichung in Vektornotation.

import numpy as np
import matplotlib.pyplot as plt
import matplotlib.style as style
from scipy.integrate import solve_ivp
style.use('seaborn-v0_8')

# --- Parameter ---
m       = 250.0
k_feder = 16000.0
omega_0 = np.sqrt(k_feder / m)     # = 8.0 rad/s
c_krit  = 2 * np.sqrt(k_feder * m) # kritische Dämpfung in N*s/m

x0 = 0.05   # Anfangsauslenkung in m
v0 = 0.0    # Anfangsgeschwindigkeit in m/s

print(f"omega_0 = {omega_0:.2f} rad/s")
print(f"c_krit  = {c_krit:.1f} N*s/m")

# --- Rechte Seite: gedämpfter Schwinger ---
# m * x_ddot + c * x_dot + k * x = 0
# y[0] = x (Position), y[1] = x_dot (Geschwindigkeit)
# x_ddot = (-k*x - c*x_dot) / m = (-k*y[0] - c*y[1]) / m
def f_gedaempft(t, y, c):
    x_dot  = y[1]
    x_ddot = (-k_feder * y[0] - c * y[1]) / m
    return [x_dot, x_ddot]
omega_0 = 8.00 rad/s
c_krit  = 4000.0 N*s/m

Wir wählen nacheinander die Dämpfungsgrade D=0.2D = 0.2D=0.2, D=0.5D = 0.5D=0.5, D=1.0D = 1.0D=1.0 und D=2.0D = 2.0D=2.0 und lösen mit solve_ivp die Differentialgleichung. Danach visualisieren wir die vier Schwingungen in einem gemeinsamen Diagramm.

# --- Kurvenschar für vier Dämpfungsgrade ---
t_eval = np.linspace(0, 5, 1001)
D_werte = [0.2, 0.5, 1.0, 2.0]
farben  = ['#005A94', '#E87846', '#E60000', '#484949']

fig, ax = plt.subplots()

for D, farbe in zip(D_werte, farben):
    # c = D * c_krit (Definition des Dämpfungsgrades)
    c   = D * c_krit
    sol = solve_ivp(lambda t, y, c=c: f_gedaempft(t, y, c),
                    (0, 5), [x0, v0], t_eval=t_eval)
    label = f'D = {D}'
    ax.plot(t_eval, sol.y[0] * 100, color=farbe, label=label)

ax.axhline(0, color='black', linewidth=0.8, linestyle='--')
ax.set_xlabel('Zeit in s')
ax.set_ylabel('Auslenkung in cm')
ax.set_title('Gedämpfter Schwinger: Zeitsignal')
ax.legend()
plt.tight_layout()
plt.show()

Für D<1D < 1D<1 sieht man im Phasenporträt eine Phasenkurve, die spiralförmig auf den Ursprung zuläuft. Das System schwingt, verliert aber jede Runde Energie an den Dämpfer. Für D=1D = 1D=1 und D=2D = 2D=2 schwingt das System nicht mehr: Die Auslenkung ändert ihr Vorzeichen nicht, der Zustand nähert sich monoton der Ruhelage.

Die gedämpfte Eigenkreisfrequenz beträgt ωd=ω01−D2\omega_d = \omega_0\sqrt{1-D^2}ωd​=ω0​1−D2​, was für D<1D < 1D<1 eine reelle Zahl ergibt. Bei D≥1D \geq 1D≥1 gibt es keine periodische Eigenschwingung mehr.

Erzwungene Schwingung und Resonanz¶

Bisher war die rechte Seite der DGL gleich null: keine äußere Kraft. Jetzt fügen wir eine periodische Anregung hinzu: F(t)=F0sin⁡(Ωt)F(t) = F_0\sin(\Omega t)F(t)=F0​sin(Ωt). Im realen Fahrzeugbau werden Straßenunebenheiten meist als Weganregung am Rad modelliert (vorgegebene Bewegung des Radaufstandspunktes). Hier verwenden wir der Einfachheit halber eine Kraftanregung. Sie bildet die wesentlichen Phänomene wie Resonanz und Einschwingvorgang dennoch korrekt ab.

Die DGL mx¨+cx˙+kx=F0sin⁡(Ωt)m\ddot{x} + c\dot{x} + kx = F_0\sin(\Omega t)mx¨+cx˙+kx=F0​sin(Ωt) ist nicht-autonom: die rechte Seite hängt explizit von ttt ab. solve_ivp kann das ohne Anpassung lösen, weil f(t, y) den Zeitpunkt t immer als erstes Argument erhält. Wir implementieren die neue rechte Seite.

# --- Parameter ---
m       = 250.0
k_feder = 16000.0
omega_0 = np.sqrt(k_feder / m)
c_krit  = 2 * np.sqrt(k_feder * m)
D       = 0.2
c       = D * c_krit    # = 800 N*s/m
F0      = 500.0         # Kraftamplitude in N

# --- Erzwungener Schwinger (nicht-autonom: t taucht in f auf) ---
# m * x_ddot + c * x_dot + k * x = F0 * sin(Omega * t)
# x_ddot = (-k*x - c*x_dot + F0*sin(Omega*t)) / m
def f_erzwungen(t, y, Omega):
    x_dot  = y[1]
    x_ddot = (-k_feder * y[0] - c * y[1] + F0 * np.sin(Omega * t)) / m
    return [x_dot, x_ddot]

Mit dieser Funktion f_erzwungen können wir nun die erzwungene Schwingung untersuchen.

Im ersten Schritt wählen wir eine Anregungsfrequenz Ω\OmegaΩ nahe der Eigenkreisfrequenz ω0\omega_0ω0​ und starten aus der Ruhelage x(0)=0x(0)=0x(0)=0, x˙(0)=0\dot{x}(0)=0x˙(0)=0. Anschließend integrieren wir die DGL über eine ausreichend lange Zeit, damit der Einschwingvorgang weitgehend abgeklungen ist.

# --- Simulation nahe Resonanz: Omega = omega_0 ---
# Für kleine D liegt die tatsächliche Resonanzfrequenz
# Omega_R = omega_0 * sqrt(1 - 2*D^2) nahe bei omega_0.
# Bei D = 0.2 gilt Omega_R ≈ 0.96 * omega_0, d.h. Abweichung < 4 %.
Omega_res = omega_0
t_end     = 30.0
t_eval    = np.linspace(0, t_end, 3001)

sol = solve_ivp(lambda t, y: f_erzwungen(t, y, Omega_res),
                (0, t_end), [0.0, 0.0], t_eval=t_eval)

# --- Stationäre Amplitude aus dem letzten Drittel ablesen ---
# Im letzten Drittel ist der Einschwingvorgang praktisch abgeklungen
n_last  = len(t_eval) // 3
A_stat  = np.max(np.abs(sol.y[0, -n_last:]))

Im zweiten Schritt haben wir aus dem letzten Drittel der Zeitreihe die stationäre Amplitude AstatA_\text{stat}Astat​ numerisch bestimmt.

Nun möchten wir diese numerische Amplitude mit der analytischen Lösung vergleichen. Für die Resonanzanregung mit Ω=ω0\Omega = \omega_0Ω=ω0​ lautet die stationäre Amplitude

A=F02Dk .A = \frac{F_0}{2 D k} \,.A=2DkF0​​.

Im dritten Schritt berechnen wir diese analytische Amplitude, vergleichen sie mit dem numerischen Wert und stellen den Einschwingvorgang im Zeitbereich dar.

# Analytische Formel für Omega = omega_0: A = F0 / (2*D*k)
# Herleitung: bei Omega = omega_0 gilt k - m*omega_0^2 = 0,
# sodass A = F0 / sqrt((c*omega_0)^2) = F0 / (c*omega_0) = F0 / (2*D*k)
A_stat_ana = F0 / (2 * D * k_feder)

print(f"Stationäre Amplitude (numerisch):  {A_stat * 100:.2f} cm")
print(f"Stationäre Amplitude (analytisch): {A_stat_ana * 100:.2f} cm")

# --- Plot: Einschwingvorgang und stationärer Zustand ---
fig, ax = plt.subplots(figsize=(9, 3.5))
ax.plot(t_eval, sol.y[0] * 100, color='#005A94', linewidth=0.8)

# Markierung Einschwingvorgang / stationär
t_grenze = t_eval[-n_last]
ax.axvline(t_grenze, color='#E60000', linestyle='--', linewidth=1.5,
           label=f'Grenze Einschwingvorgang / stationär')
ax.axhline( A_stat * 100, color='#E87846', linestyle=':', linewidth=1.5,
           label=f'A_stat = {A_stat*100:.1f} cm')
ax.axhline(-A_stat * 100, color='#E87846', linestyle=':', linewidth=1.5)

ax.set_xlabel('Zeit in s')
ax.set_ylabel('Auslenkung in cm')
ax.set_title(f'Erzwungene Schwingung nahe Resonanz (Omega0 = {omega_0:.1f} rad/s, D = {D})')
ax.legend(fontsize=9)
plt.tight_layout()
plt.show()

Vor der roten Linie überlagern sich Einschwingvorgang und stationäre Schwingung. Im letzten Drittel ist der Einschwingvorgang praktisch abgeklungen, und die Amplitude ist konstant. Die numerische und die analytische stationäre Amplitude stimmen sehr gut überein.

Für kleine Dämpfung DDD ist die Energieübertragung von der Anregung auf den Schwinger bei Ω≈ω0\Omega \approx \omega_0Ω≈ω0​ am größten. Das nennt man Resonanz. Das genaue Amplitudenmaximum liegt bei der Resonanzfrequenz ΩR=ω01−2D2\Omega_R = \omega_0\sqrt{1-2D^2}ΩR​=ω0​1−2D2​, die für kleine DDD nahezu mit ω0\omega_0ω0​ übereinstimmt (bei D=0.2D = 0.2D=0.2 beträgt die Abweichung weniger als 4 %). Für kleine Dämpfung (D≪1D \ll 1D≪1) kann die Resonanzamplitude ein Vielfaches der statischen Auslenkung F0/kF_0/kF0​/k betragen.

Methodenübersicht: DGL in Kapitel 10 und 11¶

Alle Differentialgleichungen, die wir in Kapitel 10 und 11 gelöst haben, folgen demselben Muster: f(t, y) zurückgeben, y0 angeben, solve_ivp aufrufen. Der einzige Unterschied ist die Länge von y0 und die Anzahl der Rückgabewerte.

Der Code für solve_ivp ist in allen vier Fällen identisch. Wächst ein System auf drei oder mehr Zustände (zum Beispiel zwei gekoppelte Massen), verlängert sich nur y0 und die Rückgabeliste von f.

import numpy as np
from scipy.integrate import solve_ivp

# --- Demonstrationsvergleich: 1 Zustand (Kap. 10) vs. 2 Zustände (Kap. 11) ---
m = 250.0; k_feder = 16000.0; c = 800.0

# Kap. 10: Abkühlung (1 Zustand)
def f_abkuehlung(t, y):
    return [-0.1 * (y[0] - 20.0)]        # Rückgabe: Liste mit EINEM Eintrag

# Kap. 11: Gedämpfter Schwinger (2 Zustände)
def f_schwinger(t, y):
    return [y[1],                          # Rückgabe: Liste mit ZWEI Einträgen
            (-k_feder * y[0] - c * y[1]) / m]

sol_abk = solve_ivp(f_abkuehlung, (0, 50), [80.0])
sol_sch = solve_ivp(f_schwinger,  (0,  5), [0.05, 0.0])

print(f"Abkühlung:  sol.y.shape = {sol_abk.y.shape}  (1 Zustand)")
print(f"Schwinger:  sol.y.shape = {sol_sch.y.shape}  (2 Zustände)")

Zusammenfassung¶

Der Dämpfungsgrad D=c/(2km)D = c/(2\sqrt{km})D=c/(2km​) bestimmt das qualitative Verhalten: Für D<1D < 1D<1 schwingt das System aus, für D=1D = 1D=1 kehrt es am schnellsten ohne Überschwingen zurück, für D>1D > 1D>1 kriecht es monoton in das Gleichgewicht. Die erzwungene Schwingung ist nicht-autonom, weil F0sin⁡(Ωt)F_0\sin(\Omega t)F0​sin(Ωt) explizit von ttt abhängt. solve_ivp löst sie ohne Anpassung. Die stationäre Amplitude lässt sich aus dem letzten Zeitdrittel als max(|x|) ablesen. Bei Ω=ω0\Omega = \omega_0Ω=ω0​ gilt für die stationäre Amplitude die einfache Formel A=F0/(2Dk)A = F_0/(2Dk)A=F0​/(2Dk). Resonanz tritt auf, wenn Ω≈ω0\Omega \approx \omega_0Ω≈ω0​: Das genaue Maximum liegt bei ΩR=ω01−2D2\Omega_R = \omega_0\sqrt{1-2D^2}ΩR​=ω0​1−2D2​, das für kleine DDD nahe bei ω0\omega_0ω0​ liegt.
