3.4 Wie viel bringt eine dickere Dämmung?

In Kapitel 3.3 haben wir die Temperaturen und den Wärmestrom in einer dreischichtigen Wand berechnet. In diesem Kapitel erweitern wir die Wand um eine Dämmschicht und untersuchen mit einer Parameterstudie, wie stark der Wärmestrom sinkt, wenn wir die Dämmung verstärken. Bearbeiten Sie die Teilaufgaben möglichst zu zweit und der Reihe nach.

Projekt: Parameterstudie zur Dämmstärke (✩✩)

Eine Außenwand besteht aus vier Schichten. Innen herrscht TLA=293 KT_{LA} = 293\,\text{K}TLA​=293K (20 °C), außen TDR=263 KT_{DR} = 263\,\text{K}TDR​=263K (−10 °C).

AInnenputz0.04
BMauerwerk0.5
CDämmungRCR_CRC​ (variabel)
DAußenputz0.04

Die Unbekannten sind die drei Grenzflächentemperaturen TABT_{AB}TAB​, TBCT_{BC}TBC​, TCDT_{CD}TCD​ und der Wärmestrom QQQ. Wie in Kapitel 3.3 gilt für jede Schicht Q=ΔTi/RiQ = \Delta T_i / R_iQ=ΔTi​/Ri​.

Teil 1: Das Gleichungssystem aufstellen

Formen Sie die vier Schichtgleichungen so um, dass alle Unbekannten links stehen (multiplizieren Sie jede mit ihrem RiR_iRi​). Schreiben Sie das Ergebnis als Matrixgleichung A⋅x⃗=b⃗\mathbf{A} \cdot \vec{x} = \vec{b}A⋅x=b mit x⃗=(TAB, TBC, TCD, Q)⊤\vec{x} = (T_{AB},\ T_{BC},\ T_{CD},\ Q)^\topx=(TAB​, TBC​, TCD​, Q)⊤. Die Matrix hat dieselbe Struktur wie in Kapitel 3.3, nur mit einer Zeile und einer Spalte mehr.

# Code-Zelle
Lösung Teil 1

Die umgeformten Gleichungen lauten:

TAB+RAQ=TLAT_{AB} + R_A Q = T_{LA}TAB​+RA​Q=TLA​
−TAB+TBC+RBQ=0-T_{AB} + T_{BC} + R_B Q = 0−TAB​+TBC​+RB​Q=0
−TBC+TCD+RCQ=0-T_{BC} + T_{CD} + R_C Q = 0−TBC​+TCD​+RC​Q=0
−TCD+RDQ=−TDR-T_{CD} + R_D Q = -T_{DR}−TCD​+RD​Q=−TDR​

Daraus die Matrixform:

(+100RA−1+10RB0−1+1RC00−1RD)⋅(TABTBCTCDQ)=(TLA00−TDR)\begin{pmatrix} +1 & 0 & 0 & R_A \\ -1 & +1 & 0 & R_B \\ 0 & -1 & +1 & R_C \\ 0 & 0 & -1 & R_D \end{pmatrix} \cdot \begin{pmatrix} T_{AB} \\ T_{BC} \\ T_{CD} \\ Q \end{pmatrix} = \begin{pmatrix} T_{LA} \\ 0 \\ 0 \\ -T_{DR} \end{pmatrix}⎝⎛​+1−100​0+1−10​00+1−1​RA​RB​RC​RD​​⎠⎞​⋅⎝⎛​TAB​TBC​TCD​Q​⎠⎞​=⎝⎛​TLA​00−TDR​​⎠⎞​
Teil 2: Für eine feste Dämmung lösen

Legen Sie A und b für RC=1.0 K/WR_C = 1.0\,\text{K/W}RC​=1.0K/W als NumPy-Arrays an. Prüfen Sie die Determinante, lösen Sie mit np.linalg.solve und geben Sie die drei Grenzflächentemperaturen (in °C) und den Wärmestrom aus. Sichern Sie das Ergebnis mit einer Probe ab.

# Code-Zelle
Lösung Teil 2
import numpy as np

R_A = 0.04
R_B = 0.5
R_C = 1.0
R_D = 0.04
T_LA = 293.0
T_DR = 263.0

A = np.array([
    [+1.0,  0.0,  0.0, R_A],
    [-1.0, +1.0,  0.0, R_B],
    [ 0.0, -1.0, +1.0, R_C],
    [ 0.0,  0.0, -1.0, R_D],
])
b = np.array([T_LA, 0.0, 0.0, -T_DR])

print(f'Determinante: {np.linalg.det(A):.4f}')

x = np.linalg.solve(A, b)
T_AB, T_BC, T_CD, Q = x

print(f'T_AB = {T_AB - 273.15:.1f} °C')
print(f'T_BC = {T_BC - 273.15:.1f} °C')
print(f'T_CD = {T_CD - 273.15:.1f} °C')
print(f'Q    = {Q:.2f} W')
print('Probe bestanden:', np.allclose(A @ x, b))

Mit RC=1.0R_C = 1.0RC​=1.0 K/W ergibt sich ein Wärmestrom von rund 19.0 W. Die Temperatur fällt von 20 °C innen über den Innenputz kaum merklich auf 19.1 °C, dann über das Mauerwerk auf 9.6 °C und schließlich innerhalb der Dämmung steil auf −9.4 °C. Fast die gesamte Temperaturdifferenz liegt über der Dämmschicht.

Teil 3: Parameterstudie und Diagramm

Untersuchen Sie, wie der Wärmestrom von der Dämmstärke abhängt. Variieren Sie RCR_CRC​ mit

r_c_werte = np.linspace(0.0, 3.0, 31)

Lösen Sie für jeden Wert das Gleichungssystem, speichern Sie den Wärmestrom in einem Array q_werte und stellen Sie q_werte über r_c_werte als Linienplot dar (Achsenbeschriftung, Titel, Gitter).

# Code-Zelle
Lösung Teil 3
import numpy as np
import matplotlib.pyplot as plt
import matplotlib.style as style
style.use('seaborn-v0_8')

R_A, R_B, R_D = 0.04, 0.5, 0.04
T_LA, T_DR = 293.0, 263.0

r_c_werte = np.linspace(0.0, 3.0, 31)
q_werte = np.zeros(31)

for i, r_c in enumerate(r_c_werte):
    A = np.array([
        [+1.0,  0.0,  0.0, R_A],
        [-1.0, +1.0,  0.0, R_B],
        [ 0.0, -1.0, +1.0, r_c],
        [ 0.0,  0.0, -1.0, R_D],
    ])
    b = np.array([T_LA, 0.0, 0.0, -T_DR])
    x = np.linalg.solve(A, b)
    q_werte[i] = x[3]

fig, ax = plt.subplots(figsize=(7, 4))
ax.plot(r_c_werte, q_werte)
ax.set_xlabel('Wärmewiderstand der Dämmung in K/W')
ax.set_ylabel('Wärmestrom in W')
ax.set_title('Wärmestrom in Abhängigkeit von der Dämmstärke')
ax.grid(True)
plt.show()

Für jeden Wert von RCR_CRC​ lösen wir ein eigenes Gleichungssystem. Nur der eine Matrixeintrag in Zeile 3, Spalte 4 ändert sich, alles andere bleibt gleich.

Teil 4: Das Diagramm auswerten

Beantworten Sie in eigenen Worten:

  1. Wie verändert sich der Wärmestrom, wenn RCR_CRC​ von 0 auf 0.5 K/W steigt, und wie, wenn es von 2.5 auf 3.0 K/W steigt?

  2. Was bedeutet die Form der Kurve für die Frage, ob sich eine immer dickere Dämmung lohnt?

Lösung Teil 4

  1. Am Anfang bringt zusätzliche Dämmung viel: Von RC=0R_C = 0RC​=0 bis RC=0.5R_C = 0.5RC​=0.5 K/W fällt der Wärmestrom von rund 52 W auf rund 28 W. Am Ende bringt sie wenig: Von RC=2.5R_C = 2.5RC​=2.5 bis RC=3.0R_C = 3.0RC​=3.0 K/W sinkt er nur noch von etwa 9.7 W auf 8.4 W.

  2. Die Kurve fällt zuerst steil und wird dann immer flacher. Der Nutzen jeder weiteren Dämmschicht nimmt ab. Ab einem gewissen Punkt steht der zusätzliche Materialaufwand in keinem Verhältnis mehr zur eingesparten Wärme. Das nennt man den abnehmenden Grenznutzen der Dämmung.

Zusatzaufgabe: Halbierung des Wärmestroms (✩✩✩)

Bestimmen Sie aus der Parameterstudie, bei welchem RCR_CRC​ der Wärmestrom auf die Hälfte des Wertes ohne Dämmung (RC=0R_C = 0RC​=0) gesunken ist.

  1. Der Wert ohne Dämmung steht in q_werte[0]. Bilden Sie das Ziel q_ziel = q_werte[0] / 2.

  2. Finden Sie den Index des q_werte-Eintrags, der q_ziel am nächsten liegt, mit np.argmin(np.abs(q_werte - q_ziel)).

  3. Geben Sie das zugehörige RCR_CRC​ aus und markieren Sie den Punkt im Diagramm aus Teil 3 mit einem zweiten ax.scatter()-Aufruf.

# Code-Zelle
Lösung Zusatzaufgabe
q_ziel = q_werte[0] / 2
i_halb = np.argmin(np.abs(q_werte - q_ziel))
r_c_halb = r_c_werte[i_halb]

print(f'Wärmestrom ohne Dämmung: {q_werte[0]:.1f} W')
print(f'Halber Wärmestrom:       {q_ziel:.1f} W')
print(f'erreicht bei R_C = {r_c_halb:.2f} K/W')

fig, ax = plt.subplots(figsize=(7, 4))
ax.plot(r_c_werte, q_werte, label='Wärmestrom')
ax.scatter(r_c_halb, q_werte[i_halb], color='red', zorder=5,
           label='halber Wärmestrom')
ax.set_xlabel('Wärmewiderstand der Dämmung in K/W')
ax.set_ylabel('Wärmestrom in W')
ax.set_title('Halbierung des Wärmestroms')
ax.legend()
ax.grid(True)
plt.show()

Der Wärmestrom ohne Dämmung beträgt rund 52 W. Die Hälfte davon, rund 26 W, wird schon bei einer Dämmung mit RC≈0.6R_C \approx 0.6RC​≈0.6 K/W erreicht. Um ihn noch einmal zu halbieren, bräuchte man deutlich mehr als das Doppelte an Dämmwiderstand, was wieder den abnehmenden Grenznutzen zeigt.
