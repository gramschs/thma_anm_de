Projekt: Schwenkarm am Förderband (✩✩)

In einer Verpackungsanlage kommen Gehäusedeckel auf einem Förderband an. Ein Schwenkarm nimmt jeden Deckel vom Band und legt ihn in eine Kiste. Der Arm hat ein einziges Drehgelenk im Ursprung und ist vom Gelenk bis zum Greifer L=0.6 mL = 0.6\,\text{m}L=0.6m lang. def zeichne_roboter(arme, bauteile=None, ziele=None, bahn=None, umgebung=None,
                    beschriftungen=None, titel='', grenze=0.8):
    """Zeichnet einen Roboterarm in der Draufsicht.

    arme: Punkte eines Arms als Array, Zeile = [x, y], vom ersten Gelenk bis
          zum Greifer, oder eine Liste solcher Arrays für mehrere Stellungen
    bauteile: Eckpunkte des Bauteils im Greifer als Array, oder eine Liste
              mit einem Array pro Stellung (optional)
    ziele: Zielpunkte als Array, Zeile = [x, y], werden als Kreuze markiert (optional)
    bahn: Greiferpositionen als Array, Zeile = [x, y], werden als gestrichelte
          Linie mit Punkten gezeichnet (optional)
    umgebung: Eckpunkte von Flächen wie Förderband oder Kiste als Array oder
              Liste von Arrays, werden grau gefüllt (optional)
    beschriftungen: Legendentexte, einer pro Stellung (optional)
    titel: Diagrammtitel
    grenze: sichtbarer Bereich von -grenze bis +grenze in m
    """
    blau, rot, orange, grau = '#005A94', '#E60000', '#E87846', '#484949'
    farben = [blau, rot, orange, grau]
    if isinstance(arme, np.ndarray):
        arme = [arme]
    if isinstance(bauteile, np.ndarray):
        bauteile = [bauteile]
    if isinstance(umgebung, np.ndarray):
        umgebung = [umgebung]
    fig, ax = plt.subplots(figsize=(6, 6))

    # Umgebung: Flächen wie Förderband oder Kiste
    if umgebung is not None:
        for flaeche in umgebung:
            ax.fill(flaeche[:, 0], flaeche[:, 1], facecolor='#DDDEDE',
                    edgecolor=grau, linewidth=1, zorder=0)

    # Sockel im Ursprung
    ax.add_patch(plt.Circle((0, 0), 0.06, facecolor='#CCDEE9', edgecolor=blau,
                            linewidth=1.5, zorder=1))

    # Greiferbahn als gestrichelte Linie mit Punkten
    if bahn is not None:
        ax.plot(bahn[:, 0], bahn[:, 1], color=grau, linestyle='--', linewidth=1,
                marker='o', markersize=3, label='Greiferbahn', zorder=1)

    # Arme: Gelenke als Kreise, Greifer als Quadrat, Bauteil gelb gefüllt
    for k in range(len(arme)):
        farbe = farben[k % len(farben)]
        punkte = arme[k]
        label = None if beschriftungen is None else beschriftungen[k]
        ax.plot(punkte[:, 0], punkte[:, 1], color=farbe, linewidth=6,
                solid_capstyle='round', label=label, zorder=2)
        ax.scatter(punkte[:-1, 0], punkte[:-1, 1], s=50, color='white',
                   edgecolor=farbe, linewidth=2, zorder=3)
        ax.scatter(punkte[-1, 0], punkte[-1, 1], s=60, marker='s', color=farbe,
                   zorder=3)
        if bauteile is not None:

            ax.fill(ecken[:, 0], ecken[:, 1], facecolor='#FFEC7F',

# Funktion aus Kapitel 5.1
def drehmatrix(winkel):
    """Drehmatrix für eine Drehung um den Ursprung, winkel in Radiant."""
    return np.array([
        [np.cos(winkel), -np.sin(winkel)],
        [np.sin(winkel),  np.cos(winkel)],
    ])

# Schwenkarm in Grundstellung in m, Zeile = [x, y]
arm = np.array([
    [0.0, 0.0],   # Gelenk
    [0.6, 0.0],   # Greifer
])

# Ecken des Deckels unter dem Greifer in m
deckel = np.array([
    [0.55, -0.03],
    [0.65, -0.03],
    [0.65,  0.03],
    [0.55,  0.03],

def greiferbahn(anzahl_punkte):
    """Greiferpositionen beim Schwenk von 0 Grad bis zum Ablagewinkel."""
    winkel = np.linspace(0, ablagewinkel, anzahl_punkte)
    bahn = np.zeros((anzahl_punkte, 2))
    for k in range(anzahl_punkte):
        bahn[k] = drehmatrix(np.deg2rad(winkel[k])) @ arm[1]
    return bahn

def weglaenge(bahn):
    """Summe der geraden Abstände zwischen aufeinanderfolgenden Punkten."""
    laenge = 0.0
    for k in range(len(bahn) - 1):
        differenz = bahn[k + 1] - bahn[k]
        laenge += np.sqrt(differenz[0]**2 + differenz[1]**2)
    return laenge

# Exakte Bogenlänge: Radius mal Winkel in Radiant
bogen = 0.6 * np.deg2rad(ablagewinkel)

Lösung Abschlussfrage

  1. Der Arm hat nur ein Gelenk. Der Greifer bewegt sich deshalb immer auf einem Kreis mit Radius 0.6 m0.6\,\text{m}0.6m um das Gelenk, und seine Position ist allein durch den Winkel α\alphaα festgelegt. Eine Kistenmitte bei (−0.30,0.30)(-0.30, 0.30)(−0.30,0.30) liegt nur 0.424 m0.424\,\text{m}0.424m vom Gelenk entfernt. Der Greifer käme ihr nie näher als 0.6 m−0.424 m=0.176 m0.6\,\text{m} - 0.424\,\text{m} = 0.176\,\text{m}0.6m−0.424m=0.176m und würde die Kiste verfehlen. Um Punkte in einer ganzen Fläche zu erreichen, braucht der Arm ein zweites Gelenk am Ende des ersten Arms, wie der SCARA-Roboter aus Kapitel 5.1.

  2. Die Orientierung des Deckels ist fest an den Schwenkwinkel gekoppelt: Wenn der Arm um 140°140°140° schwenkt, dreht sich auch der Deckel um 140°140°140°. Um ihn gerade abzulegen, müsste der Deckel zusätzlich um seinen eigenen Mittelpunkt gedreht werden, wegen seiner Symmetrie genügen dafür 40°40°40°. Echte Anlagen haben dafür einen drehbaren Greifer. Unsere Drehmatrix dreht aber nur um den Ursprung. Eine Drehung um einen anderen Punkt setzt sich aus Drehen und Verschieben zusammen. Wie wir beides in einer einzigen Matrix beschreiben, lernen wir in Kapitel 5.3.
