11.1 Systeme 1. Ordnung und freie Schwingung

In Kapitel 10 haben wir solve_ivp eingesetzt, um die Temperatur eines abkühlenden Metallstabs zu berechnen. Der Zustandsvektor hatte genau einen Eintrag: die Temperatur TTT. Nun stellen wir die Frage anders: Ein Fahrzeug trifft auf eine Bodenwelle und wird dabei einmalig um x0x_0x0​ ausgelenkt. Nach dem Überfahren der Unebenheit schwingt die Karosserie frei weiter, da sie auf einer Feder sitzt. Das Newtonsche Gesetz ma=Fma = Fma=F ergibt für die freie Schwingung bei kleinen Auslenkungen um die Gleichgewichtslage

m x¨(t)+k x(t)=0.m\,\ddot{x}(t) + k\,x(t) = 0.mx¨(t)+kx(t)=0.

Das ist eine Differentialgleichung zweiter Ordnung: Es taucht x¨\ddot{x}x¨ auf. solve_ivp erwartet aber Systeme erster Ordnung. Wir zeigen in diesem Abschnitt, wie wir jede skalare DGL 2. Ordnung durch eine einfache Substitution in zwei skalare Differentialgleichungen 1. Ordnung umschreiben und damit solve_ivp ohne weitere Anpassungen einsetzen können.

Lernziele¶

Lernziele

  • Sie können eine skalare DGL 2. Ordnung durch die Substitution y1=xy_1 = xy1​=x, y2=x˙y_2 = \dot{x}y2​=x˙ in ein System zweier Differentialgleichungen 1. Ordnung überführen und den Zustandsvektor y=[x, x˙]⊤\mathbf{y} = [x,\, \dot{x}]^\topy=[x,x˙]⊤ benennen.

  • Sie können solve_ivp für ein zweidimensionales System aufrufen, die Anfangsbedingung als y0=[x0, v0] angeben und sol.y[0] (Position) sowie sol.y[1] (Geschwindigkeit) korrekt auslesen.

  • Sie kennen die Eigenkreisfrequenz ω0=k/m\omega_0 = \sqrt{k/m}ω0​=k/m​ und können sie aus dem Zeitsignal x(t)x(t)x(t) ablesen.

  • Sie können ein Phasenporträt (x˙\dot{x}x˙ über xxx) erstellen und erklären, warum es beim ungedämpften Schwinger eine Ellipse ergibt.

Von der DGL 2. Ordnung zum System 1. Ordnung¶

Warum kann solve_ivp eine DGL zweiter Ordnung nicht direkt lösen? solve_ivp erwartet die Signatur f(t, y), wobei y ein Vektor von Zustandsgrößen ist und f deren zeitliche Ableitungen zurückgibt. Das funktioniert nur für Systeme erster Ordnung. Wir müssen x¨\ddot{x}x¨ also loswerden.

Die Idee ist einfach: Wir benennen die beiden Größen, die wir berechnen wollen, mit y1=xy_1 = xy1​=x (Position) und y2=x˙y_2 = \dot{x}y2​=x˙ (Geschwindigkeit). Dann gilt y˙1=y2\dot{y}_1 = y_2y˙​1​=y2​ (die Ableitung der Position ist die Geschwindigkeit) und y˙2=x¨=−(k/m) x=−(k/m) y1\dot{y}_2 = \ddot{x} = -(k/m)\,x = -(k/m)\,y_1y˙​2​=x¨=−(k/m)x=−(k/m)y1​ (aus der DGL). Statt einer DGL 2. Ordnung haben wir jetzt zwei Differentialgleichungen 1. Ordnung:

y˙1=y2,y˙2=−(km)y1.\dot{y}_1 = y_2, \qquad \dot{y}_2 = -\left(\frac{k}{m}\right)y_1.y˙​1​=y2​,y˙​2​=−(mk​)y1​.

Diese schreiben wir in Vektornotation:

ddt(y1y2)=(y2−km y1).\frac{d}{dt}\begin{pmatrix} y_1 \\ y_2 \end{pmatrix} = \begin{pmatrix} y_2 \\ -\dfrac{k}{m}\,y_1 \end{pmatrix}.dtd​(y1​y2​​)=(y2​−mk​y1​​).

In Kapitel 10 hatte y einen Eintrag (y=[T]y = [T]y=[T]), hier hat y zwei Einträge: y=[x, x˙]y = [x,\, \dot{x}]y=[x,x˙]. Das ist der einzige Unterschied im Code. Genau dieses Vorgehen klappt für jede skalare DGL zweiter Ordnung: Wir wählen als Zustände die gesuchte Größe und ihre erste Ableitung.

Als Nächstes setzen wir das Modell auf.

import numpy as np
import matplotlib.pyplot as plt
import matplotlib.style as style
from scipy.integrate import solve_ivp
style.use('seaborn-v0_8')

# --- Modellparameter: stark vereinfachtes 1-Massen-Feder-Modell ---
# (Viertelfahrzeug ohne Dämpfung, 1 Freiheitsgrad)
# m = Viertel der Fahrzeugmasse (eine Radaufhängung)
# k_feder = Federkonstante der Radaufhängung
m       = 250.0              # Masse in kg
k_feder = 16000.0            # Federkonstante in N/m

# T_0 = 2*pi / omega_0: Zeit für eine vollständige Schwingung
omega_0 = np.sqrt(k_feder / m)    # Eigenkreisfrequenz in rad/s
f_0     = omega_0 / (2 * np.pi)   # Eigenfrequenz in Hz
T_0     = 1 / f_0                 # Schwingungsdauer in s

print(f"Eigenkreisfrequenz: omega_0 = {omega_0:.4f} rad/s")
print(f"Eigenfrequenz:      f_0     = {f_0:.4f} Hz")

Als Nächstes bestimmen wir die exakte analytische Lösung der Schwingungsgleichung, um sie später mit der numerisch ermittelten Lösung vergleichen zu können. Mit der Eigenkreisfrequenz

ω0=km\omega_0 = \sqrt{\frac{k}{m}}ω0​=mk​​

lautet die ungedämpfte Schwingungsgleichung

x¨+ω02x=0 .\ddot{x} + \omega_0^2 x = 0 \,.x¨+ω02​x=0.

Die Eigenkreisfrequenz ω0=k/m=8 rad/s\omega_0 = \sqrt{k/m} = 8\,\text{rad/s}ω0​=k/m​=8rad/s beschreibt, wie schnell die Feder die Masse zurückzieht. Die Karosserie schwingt etwa 1.3 Mal pro Sekunde (f0=ω0/2πf_0 = \omega_0/2\pif0​=ω0​/2π). Ohne Dämpfung würde das Fahrzeug nach einer Bodenwelle endlos weiter wippen.

Aus der Vorlesung Mathematik 3 kennen wir die allgemeine Lösung

x(t)=Acos⁡(ω0t)+Bsin⁡(ω0t).x(t) = A \cos(\omega_0 t) + B \sin(\omega_0 t).x(t)=Acos(ω0​t)+Bsin(ω0​t).

Mit den Anfangsbedingungen x(0)=x0x(0) = x_0x(0)=x0​ und x˙(0)=0\dot{x}(0) = 0x˙(0)=0 folgern wir

A=x0,B=0 ,A = x_0, \qquad B = 0 \,,A=x0​,B=0,

also lautet die analytische Lösung

x(t)=x0cos⁡(ω0t) .x(t) = x_0 \cos(\omega_0 t) \,.x(t)=x0​cos(ω0​t).

t_ref = np.linspace(0, 5, 501)

# Visualisierung der analytischen Lösung

ax.set_xlabel('Zeit in s')

solve_ivp für den Federschwinger¶

Wie schreibt man f(t, y) für eine DGL zweiter Ordnung? Wir übersetzen das System von oben direkt in Python: y[0] ist die Position xxx, y[1] ist die Geschwindigkeit x˙\dot{x}x˙. Die Funktion gibt beide Ableitungen zurück, genau wie in Kapitel 10, nur mit zwei Einträgen statt nur einem Eintrag.

# --- Anfangsbedingungen ---
x0 = 0.05   # Anfangsauslenkung in m (Bodenwelle)
v0 = 0.0    # Anfangsgeschwindigkeit in m/s (aus der Ruhe)

# --- Rechte Seite als System 1. Ordnung ---
# y[0] = x       (Position in m)
# y[1] = x_dot   (Geschwindigkeit in m/s)
#
# Ableitung von y[0]: dx/dt = x_dot = y[1]
# Ableitung von y[1]: d(x_dot)/dt = x_ddot = -k/m * x = -(k_feder/m) * y[0]
#
# WICHTIG: Rückgabe in derselben Reihenfolge wie y0 = [x0, v0]
def f_schwinger(t, y):
    x_dot  = y[1]                      # Ableitung der Position = Geschwindigkeit
    x_ddot = -(k_feder / m) * y[0]     # Ableitung der Geschwindigkeit = Beschleunigung
    return [x_dot, x_ddot]

# --- solve_ivp Aufruf: y0 hat jetzt ZWEI Einträge ---
t_eval = np.linspace(0, 5, 501)
sol = solve_ivp(fun=f_schwinger, t_span=(0, 5), y0=[x0, v0], t_eval=t_eval)

# --- Rückgabe auslesen ---
# sol.y.shape = (2, 501): Zeile 0 = Position, Zeile 1 = Geschwindigkeit
print(f"Integration erfolgreich: {sol.success}")
print(f"sol.y.shape = {sol.y.shape}  --> {sol.y.shape[0]} Zustände, "
      f"{sol.y.shape[1]} Zeitpunkte")
Integration erfolgreich: True
sol.y.shape = (2, 501)  --> 2 Zustände, 501 Zeitpunkte

Das Phasenporträt¶

Bisher haben wir x(t)x(t)x(t) und x˙(t)\dot{x}(t)x˙(t) jeweils gegen die Zeit aufgetragen. Es gibt eine zweite Möglichkeit: das Phasenporträt. Dabei tragen wir x˙\dot{x}x˙ auf der y-Achse gegen xxx auf der x-Achse auf, ohne die Zeit explizit darzustellen. Jeder Punkt im Phasenporträt beschreibt einen vollständigen Systemzustand: Wo ist die Masse, und wie schnell bewegt sie sich?

m       = 250.0
k_feder = 16000.0

def f_schwinger(t, y):
    return [y[1], -(k_feder / m) * y[0]]

t_eval = np.linspace(0, 10, 2001)

# --- Drei verschiedene Anfangsbedingungen (unterschiedlich viel Energie) ---
anfangsbedingungen = [
    (0.02, 0.0),   # kleine Auslenkung, kleines x0
    (0.05, 0.0),   # mittlere Auslenkung
    (0.00, 0.8),   # Impuls statt Auslenkung (v0 != 0)
]
farben = ['#005A94', '#E60000', '#E87846']
labels = ['x0=2 cm, v0=0', 'x0=5 cm, v0=0', 'x0=0, v0=0.8 m/s']

fig, axes = plt.subplots(1, 2, figsize=(10, 4))

for (xi, vi), farbe, label in zip(anfangsbedingungen, farben, labels):
    sol = solve_ivp(f_schwinger, (0, 10), [xi, vi], t_eval=t_eval)
    # Zeitsignal
    axes[0].plot(t_eval, sol.y[0] * 100, color=farbe, label=label)
    # Phasenporträt: x_dot über x, KEIN Zeitindex als Achse
    axes[1].plot(sol.y[0] * 100, sol.y[1], color=farbe, label=label)

axes[0].set_xlabel('Zeit in s')
axes[0].set_ylabel('Auslenkung in cm')
axes[0].set_title('Zeitsignale')
axes[0].legend(fontsize=8)

axes[1].set_xlabel('Auslenkung x in cm')
axes[1].set_ylabel('Geschwindigkeit ẋ in m/s')
axes[1].set_title('Phasenporträt')
axes[1].legend(fontsize=8)

plt.tight_layout()
plt.show()

Jede Anfangsbedingung ergibt eine geschlossene Ellipse im Phasenporträt. Das ist kein Zufall: Beim ungedämpften Schwinger bleibt die mechanische Gesamtenergie E=12mx˙2+12kx2E = \frac{1}{2}m\dot{x}^2 + \frac{1}{2}kx^2E=21​mx˙2+21​kx2 konstant. Diese Gleichung beschreibt in der xxx-x˙\dot{x}x˙-Ebene genau eine Ellipse. Größere Anfangsbedingungen bedeuten mehr Energie und damit eine größere Ellipse. In Abschnitt 11.3 fügen wir Dämpfung hinzu. Dann verliert das System Energie. Im Schwingfall mit Dämpfung laufen die Phasenkurven spiralförmig in den Ursprung ein.

Zu Frage 1: ∣x˙∣|\dot{x}|∣x˙∣ ist maximal, wenn x=0x = 0x=0 ist (Masse passiert die Ruhelage mit maximaler Geschwindigkeit, die gesamte Energie steckt in der kinetischen Energie). ∣x˙∣=0|\dot{x}| = 0∣x˙∣=0 gilt bei maximaler Auslenkung x=±xmax⁡x = \pm x_{\max}x=±xmax​ (Umkehrpunkte, die gesamte Energie steckt in der Federenergie).

Zu Frage 2: Die Energiegleichung 12mx˙2+12kx2=E\frac{1}{2}m\dot{x}^2 + \frac{1}{2}kx^2 = E21​mx˙2+21​kx2=E hat auf der xxx-Achse die Halbachse 2E/k\sqrt{2E/k}2E/k​ (in m) und auf der x˙\dot{x}x˙-Achse die Halbachse 2E/m\sqrt{2E/m}2E/m​ (in m/s). Das Verhältnis der x˙\dot{x}x˙-Halbachse zur xxx-Halbachse beträgt k/m=ω0\sqrt{k/m} = \omega_0k/m​=ω0​. In normierten Koordinaten, bei denen die x˙\dot{x}x˙-Achse durch ω0\omega_0ω0​ skaliert wird, wird die Kurve zum Kreis.

Zu Frage 3: Bleibt x0x_0x0​ unverändert, so bleibt auch die maximale Auslenkung xmax⁡=x0x_{\max} = x_0xmax​=x0​ konstant; die Halbachse in xxx-Richtung ändert sich nicht. Die Eigenkreisfrequenz steigt auf ω0neu=2k/m=2 ω0≈11.3 rad/s\omega_0^{neu} = \sqrt{2k/m} = \sqrt{2}\,\omega_0 \approx 11.3\,\text{rad/s}ω0neu​=2k/m​=2​ω0​≈11.3rad/s, und damit steigt die Maximalgeschwindigkeit vmax⁡=x0 ω0neuv_{\max} = x_0\,\omega_0^{neu}vmax​=x0​ω0neu​. Die Ellipse wird ausschließlich in x˙\dot{x}x˙-Richtung breiter.

Zusammenfassung und Ausblick¶

Eine DGL 2. Ordnung wie mx¨+kx=0m\ddot{x} + kx = 0mx¨+kx=0 wird durch die Substitution y1=xy_1 = xy1​=x, y2=x˙y_2 = \dot{x}y2​=x˙ in ein System zweier Differentialgleichungen 1. Ordnung umgeschrieben. solve_ivp löst das System ohne jede Anpassung: y0 bekommt zwei Einträge [x0, v0], f(t, y) gibt zwei Werte zurück. sol.y[0] enthält die Position, sol.y[1] die Geschwindigkeit. Die Eigenkreisfrequenz ω0=k/m\omega_0 = \sqrt{k/m}ω0​=k/m​ bestimmt, wie schnell der ungedämpfte Schwinger schwingt. Das Phasenporträt zeigt geschlossene Ellipsen, weil die mechanische Energie erhalten bleibt.

In Abschnitt 11.3 erweitern wir das Modell um Dämpfung (c x˙c\,\dot{x}cx˙). Ohne äußere Kraft laufen die Phasenkurven im gedämpften Schwingfall in den Ursprung, weil das System kontinuierlich Energie verliert. Mit einer zusätzlichen periodischen Kraft F(t)F(t)F(t) stellt sich stattdessen eine stationäre Schwingung ein, und bei passender Anregungsfrequenz entsteht Resonanz.
