# 4.3 Statische Analyse ebener Fachwerke

In den letzten beiden Kapiteln haben wir LGS aus der Elektrotechnik gelöst.
Jetzt wenden wir dasselbe Werkzeug auf die Strukturmechanik an. *Wie stark
biegt sich ein Bauteil unter Last durch, und welche Kräfte entstehen in den
einzelnen Stäben?*

Ein **ideales ebenes Fachwerk** besteht aus geraden, masselosen Stäben, die
an Knoten gelenkig verbunden sind. An den Knoten greifen Kräfte an, und
bestimmte Knoten sind fest im Raum gelagert. Die Finite-Elemente-Methode
liefert für dieses System ein LGS der Form

$$\mathbf{K}_\text{Truss} \cdot \vec{u} = \vec{F}$$

wobei $\mathbf{K}_\text{Truss}$ die globale **Steifigkeitsmatrix**, $\vec{u}$
der Verschiebungsvektor und $\vec{F}$ der Kraftvektor ist. Wir lösen es mit
`np.linalg.solve`, wie gewohnt.

## Fachwerk-Setup: Knoten, Stäbe, Lager und Lasten

Wir beginnen mit dem einfachsten nicht-trivialen Fachwerk: zwei Stäbe, die
in einem freien Knoten zusammentreffen. Die Knoten 0 und 2 sind fest gelagert,
an Knoten 1 greift eine Vertikallast an.

```{code-cell} python
import numpy as np
import matplotlib.pyplot as plt

# --- Materialeigenschaften ---
E = 2.1e11      # Elastizitätsmodul Stahl in N/m²
d = 1.0e-2      # Stabdurchmesser in m
A = np.pi * 0.25 * d**2     # Kreisquerschnitt in m²

# --- Knotenkoordinaten: NodePos[:,n] = [x_n, y_n] ---
# Knoten 0: linkes Lager   (0, 0)
# Knoten 1: freier Knoten  (1, 1)  <- Last greift hier an
# Knoten 2: rechtes Lager  (2, 0)
NodePos = np.array([
    [0.,  1.,  2.],   # x-Koordinaten
    [0.,  1.,  0.],   # y-Koordinaten
])
numNodes = NodePos.shape[1]

# --- Lagerknoten (keine Verschiebung erlaubt) ---
FixedNodeIndices = [0, 2]

# --- Konnektivitätsmatrix: C[i,j]=1 wenn Stab zwischen Knoten i und j ---
# Stab 0-1: linkes Lager  -> freier Knoten
# Stab 1-2: freier Knoten -> rechtes Lager
C = np.zeros((numNodes, numNodes))
C[0, 1] = 1
C[1, 2] = 1
C = C + C.T    # symmetrisch machen

# --- Kraftvektor: F[2*n] = Fx, F[2*n+1] = Fy an Knoten n ---
extForcesOnNodes = np.zeros((numNodes, 2))
extForcesOnNodes[1, 1] = -1000.     # 1000 N nach unten an Knoten 1
FTruss = extForcesOnNodes.flatten()

print("Knotenkoordinaten:\n", NodePos)
print("\nKonnektivitätsmatrix C:\n", C)
print("\nKraftvektor FTruss:\n", FTruss)


# --- Hilfsfunktion: Fachwerk visualisieren ---
def plotTruss(UTruss=None, scalingFactor=1000, displayForces=False,
              FTruss_plot=None, title=''):
    """Zeichnet das Fachwerk in Ausgangs- und (skalierter) Verformungslage."""
    if UTruss is None:
        UTruss = np.zeros(2 * numNodes)
    if FTruss_plot is None:
        FTruss_plot = np.zeros(2 * numNodes)

    fig, ax = plt.subplots(figsize=(7, 4))

    # Knotenposition nach Verformung (mit Skalierungsfaktor für Sichtbarkeit)
    NodePos_d = NodePos + scalingFactor * UTruss.reshape((numNodes, 2)).T

    # Stäbe: Ausgangslage grau, verformte Lage blau
    for i in range(numNodes):
        for j in range(i + 1, numNodes):
            if C[i, j]:
                ax.plot([NodePos[0,i],   NodePos[0,j]],
                        [NodePos[1,i],   NodePos[1,j]],
                        color='gray', linewidth=1.5, alpha=0.3)
                ax.plot([NodePos_d[0,i], NodePos_d[0,j]],
                        [NodePos_d[1,i], NodePos_d[1,j]],
                        color='tab:blue', linewidth=2.5)

    # Knoten
    ax.scatter(NodePos[0,:],   NodePos[1,:],   c='gray',    s=60, zorder=4, alpha=0.3)
    ax.scatter(NodePos_d[0,:], NodePos_d[1,:], c='tab:red', s=80, zorder=5)
    for n in range(numNodes):
        ax.text(NodePos_d[0,n] + 0.04, NodePos_d[1,n] + 0.04,
                f'K{n}', fontsize=9)

    # Lager als Dreiecke
    h, w = 0.12, 0.12
    for n in FixedNodeIndices:
        tx = [NodePos_d[0,n], NodePos_d[0,n]-w/2, NodePos_d[0,n]+w/2]
        ty = [NodePos_d[1,n], NodePos_d[1,n]-h,   NodePos_d[1,n]-h]
        ax.fill(tx, ty, color='tab:green', alpha=0.7)

    # Kräfte als Text ausgeben
    if displayForces:
        for n in range(numNodes):
            ax.text(NodePos_d[0,n] + 0.04, NodePos_d[1,n] - 0.12,
                    f'Fx={FTruss_plot[2*n]:.0f} N\n'
                    f'Fy={FTruss_plot[2*n+1]:.0f} N', fontsize=7)

    ax.set_title(title)
    ax.set_aspect('equal')
    ax.grid(True)
    plt.tight_layout()
    plt.show()


plotTruss(title='Fachwerk in Ausgangslage (Skalierungsfaktor = 1000)')
```

Jeder Knoten hat zwei Freiheitsgrade: eine Verschiebung in $x$ und eine in
$y$. Der Kraftvektor `FTruss` hat daher $2 \cdot n_\text{Knoten}$ Einträge.
Der Eintrag `FTruss[2*n+1]` ist die Kraft in $y$-Richtung an Knoten $n$.

## Die globale Steifigkeitsmatrix aufstellen

Jeder Stab trägt mit seiner **Elementsteifigkeitsmatrix** $\mathbf{K}_{ij}$
zur globalen Steifigkeitsmatrix bei. Für einen Stab zwischen Knoten $i$
und $j$ mit Länge $l$, Winkel $\varphi$ und Steifigkeit $k = EA/l$ gilt:

$$\mathbf{K}_{ij} = k \begin{pmatrix} \cos^2\varphi & \sin\varphi\cos\varphi \\ \cos\varphi\sin\varphi & \sin^2\varphi \end{pmatrix}$$

Diese $2\times 2$-Matrix wird an vier Stellen in die globale $(2n \times 2n)$-Matrix
eingetragen: die Diagonalblöcke der Knoten $i$ und $j$ erhalten $+\mathbf{K}_{ij}$,
die Nebendiagonalblöcke erhalten $-\mathbf{K}_{ij}$.

```{code-cell} python
# --- Globale Steifigkeitsmatrix KTruss aufstellen ---
# Dimension: 2*numNodes x 2*numNodes (je 2 Freiheitsgrade pro Knoten)
KTruss = np.zeros((2 * numNodes, 2 * numNodes))

for i in range(numNodes):
    for j in range(i + 1, numNodes):
        if C[i, j]:   # nur wenn Stab zwischen i und j existiert
            # Geometrie des Stabs i-j
            diff  = NodePos[:, j] - NodePos[:, i]
            laenge = np.linalg.norm(diff)
            phi   = np.arctan2(diff[1], diff[0])   # Winkel zur x-Achse

            # Stabsteifigkeit
            k = E * A / laenge

            # Elementsteifigkeitsmatrix (2x2) im globalen Koordinatensystem
            cp, sp = np.cos(phi), np.sin(phi)
            Kij = k * np.array([
                [cp**2,   sp * cp],
                [sp * cp, sp**2  ],
            ])

            # Kij in KTruss eintragen:
            # Diagonalblöcke (+Kij): beide Knoten werden steifer durch den Stab
            KTruss[2*i : 2*(i+1), 2*i : 2*(i+1)] += Kij
            KTruss[2*j : 2*(j+1), 2*j : 2*(j+1)] += Kij
            # Nebendiagonalblöcke (-Kij): Kopplung zwischen den Knoten
            KTruss[2*i : 2*(i+1), 2*j : 2*(j+1)] -= Kij
            KTruss[2*j : 2*(j+1), 2*i : 2*(i+1)] -= Kij

print("Globale Steifigkeitsmatrix KTruss (gerundet):")
print(np.round(KTruss * 1e-6, 2), "(× 10⁶ N/m)")
```

## Reduzieren, Lösen und Auswerten

Die Lagerknoten haben definitionsgemäß die Verschiebung null. Wir entfernen
ihre Zeilen und Spalten aus dem LGS und lösen nur das reduzierte System.
Anschließend rechnen wir die Lagerkräfte mit dem vollständigen
$\mathbf{K}_\text{Truss}$ zurück.

```{code-cell} python
# --- Freie Knoten bestimmen ---
FreeNodeIndices = [n for n in range(numNodes) if n not in FixedNodeIndices]

# --- Reduzierungsmaske: Indizes der freien Freiheitsgrade ---
# Jeder freie Knoten trägt 2 Einträge bei (x und y)
reduceMask = []
for n in FreeNodeIndices:
    reduceMask.append(2 * n)        # x-Freiheitsgrad
    reduceMask.append(2 * n + 1)    # y-Freiheitsgrad
reduceMask = np.array(reduceMask)

# --- Reduziertes LGS aufstellen ---
Fred = FTruss[reduceMask]
Kred = KTruss[reduceMask, :][:, reduceMask]

print(f"Reduzierte Steifigkeitsmatrix Kred ({Kred.shape[0]}x{Kred.shape[1]}):")
print(np.round(Kred * 1e-6, 3), "(× 10⁶ N/m)")

# --- Lösen: Kred * Ured = Fred ---
Ured = np.linalg.solve(Kred, Fred)

# --- Auf vollständigen Verschiebungsvektor erweitern ---
# Lagerknoten haben Verschiebung = 0, freie Knoten erhalten die Lösung
UTruss = np.zeros(2 * numNodes)
UTruss[reduceMask] = Ured

# --- Lagerkräfte zurückrechnen ---
# F = KTruss @ UTruss liefert alle Knotenkräfte (inkl. Lagerreaktionen)
FTruss_result = np.round(KTruss @ UTruss, 6)

# --- Ergebnisse ausgeben ---
print("\nVerschiebungen und Kräfte:")
for n in range(numNodes):
    u = UTruss[2*n : 2*(n+1)]
    F = FTruss_result[2*n : 2*(n+1)]
    gelagert = n in FixedNodeIndices
    print(f"Knoten {n} (gelagert={gelagert}): "
          f"u = [{u[0]*1e3:.4f}, {u[1]*1e3:.4f}] mm, "
          f"F = [{F[0]:.1f}, {F[1]:.1f}] N")

# --- Verformtes Fachwerk zeichnen ---
plotTruss(UTruss=UTruss, scalingFactor=1000,
          displayForces=True, FTruss_plot=FTruss_result,
          title='Verformtes Fachwerk (Skalierungsfaktor = 1000)')
```

Die Verschiebung von Knoten 1 in $x$-Richtung ist null: die Geometrie ist
symmetrisch, also heben sich die Horizontal-Komponenten beider Stäbe genau
auf. Die Lagerkräfte an den Knoten 0 und 2 müssen zusammen die externe Last
von 1000 N tragen, also je 500 N nach oben. Das lässt sich leicht von Hand
prüfen.

## Zusammenfassung und Ausblick

Die Finite-Elemente-Methode für ebene Fachwerke folgt immer demselben
Schema: Geometrie definieren, Elementsteifigkeitsmatrizen $\mathbf{K}_{ij}$
berechnen und in die globale Matrix $\mathbf{K}_\text{Truss}$ eintragen,
das LGS durch Elimination der Lagerknoten reduzieren, lösen und die
Lagerkräfte zurückrechnen.

Im nächsten Kapitel wenden wir dasselbe Vorgehen auf ein Fachwerk mit fünf
Knoten und sechs Stäben an und sehen, dass der Code sich kaum ändert,
egal wie groß das Fachwerk wird.
