# 4.2 Bandpassfilter: ein 5x5-System im Frequenzbereich

In Kapitel 4.1 haben wir einen RLC-Schwingkreis mit drei Maschen als
komplexes $3 \times 3$-LGS gelöst. Das Prinzip lässt sich auf beliebig
komplexe Netzwerke übertragen. In diesem Kapitel analysieren wir einen
**Bandpassfilter**: ein RLC-Netzwerk, das nur einen bestimmten
Frequenzbereich durchlässt und alle anderen Frequenzen dämpft.

Solche Filter spielen in der Messtechnik eine zentrale Rolle. Wollen wir aus
einem Sensorsignal gezielt eine bestimmte Schwingungsfrequenz herausfiltern,
etwa die Drehzahl einer Maschine inmitten von Störsignalen, ist ein
Bandpassfilter das richtige Werkzeug.

*Was unterscheidet dieses System vom Schwingkreis aus Kapitel 4.1?* Statt
drei Maschen haben wir jetzt fünf, also ein $5 \times 5$-LGS. Der
Lösungsalgorithmus bleibt identisch.

## Das Bandpassfilter-Netzwerk

Das Netzwerk besteht aus fünf Maschen mit den Strömen $i_1$ bis $i_5$.
Kirchhoffs Knotenregel und Maschenregel liefern fünf Gleichungen:

$$i_1 - i_2 - i_3 = 0 \qquad (1)$$
$$i_3 - i_4 - i_5 = 0 \qquad (2)$$
$$R\, i_1 + Z_C\, i_2 = U_0 \qquad (3)$$
$$-Z_C\, i_2 + Z_L\, i_3 + Z_C\, i_4 = 0 \qquad (4)$$
$$-Z_C\, i_4 + (R + Z_C)\, i_5 = 0 \qquad (5)$$

Die Ausgangsspannung am Lastwiderstand ist $u_1 = Z_C \cdot i_5$. Die
**Übertragungsfunktion** $H = u_1/U_0$ beschreibt, wie stark das Filter
eine Eingangsspannung der Frequenz $f$ abschwächt oder verstärkt.

```{code-cell} python
import numpy as np

# Bauteilwerte
R  = 4700.      # Widerstand in Ohm
C  = 2.2e-6     # Kapazität in F
L  = 0.05       # Induktivität in H
U0 = 10.        # Quellspannung in V


def getUebertragung(frequency):
    """Berechnet Amplituden- und Phasengang bei der Frequenz frequency (in Hz)."""

    # Kreisfrequenz
    omega = 2. * np.pi * frequency

    # Impedanzoperatoren
    ZC = 1. / (1j * omega * C)
    ZL = 1j * omega * L

    # --- Koeffizientenmatrix ---
    # Unbekannte: x = [i1, i2, i3, i4, i5]
    #
    # Gl. (1): i1 - i2 - i3 +   0 +    0 = 0  (Knotenregel, Knoten 1)
    # Gl. (2):  0 +  0 + i3 - i4 -   i5 = 0  (Knotenregel, Knoten 2)
    # Gl. (3): R*i1 + ZC*i2 +  0 +   0 +    0 = U0 (Maschenregel, Masche 1)
    # Gl. (4):  0 - ZC*i2 + ZL*i3 + ZC*i4 + 0 = 0  (Maschenregel, Masche 2)
    # Gl. (5):  0 +   0 +   0 - ZC*i4 + (R+ZC)*i5 = 0  (Maschenregel, Masche 3)
    A = np.array([
        [ 1.,  -1.,  -1.,   0.,     0.  ],   # Gl. (1)
        [ 0.,   0.,   1.,  -1.,    -1.  ],   # Gl. (2)
        [ R,   ZC,   0.,   0.,     0.  ],   # Gl. (3)
        [ 0.,  -ZC,  ZL,   ZC,     0.  ],   # Gl. (4)
        [ 0.,   0.,  0.,  -ZC,  R + ZC ],   # Gl. (5)
    ], dtype=complex)

    b = np.array([0., 0., U0, 0., 0.], dtype=complex)

    # Lösen
    x = np.linalg.solve(A, b)
    i1, i2, i3, i4, i5 = x

    # Ausgangsspannung und Übertragungsfunktion
    u1 = ZC * i5
    H  = u1 / U0

    # Amplitudengang (dimensionslos) und Phasengang in Grad
    amplgang = np.abs(H)
    phasgang = np.angle(H, deg=True)
    phasgang = phasgang if phasgang <= 0. else phasgang - 360.

    return amplgang, phasgang


# Test bei f = 500 Hz
ampl, phase = getUebertragung(500.)
print(f"Bei f = 500 Hz:")
print(f"  Amplitudengang a = {ampl:.4f}  (Ausgangsspannung = {ampl * U0:.4f} V)")
print(f"  Phasengang phi   = {phase:.2f}°")
```

Die Übertragungsfunktion $H = u_1/U_0$ ist dimensionslos. Ein Wert von
$|H| = 1$ bedeutet, dass die Ausgangsspannung gleich der Eingangsspannung
ist. Ein Wert von $|H| \ll 1$ zeigt, dass das Filter diese Frequenz stark
dämpft.

````{admonition} Lösung
# Frage 1: Zeile 4 (Index 3) ist Gleichung (4): -ZC*i2 + ZL*i3 + ZC*i4 = 0
# Spalte 3 (Index 2) ist der Koeffizient von i3 in Gl. (4).

# Frage 2: sehr tiefe Frequenz -> ZC sehr groß -> Filter sperrt
ampl_tief, _ = getUebertragung(0.001)
print(f"Amplitudengang bei f=0.001 Hz: {ampl_tief:.6f}")
# ZC = 1/(j*omega*C) wird für omega -> 0 sehr groß.
# Die Spannung bricht an den Kondensatoren ab, U_aus -> 0.

# Frage 3: Resonanz bei |ZL| = |ZC|
# omega*L = 1/(omega*C) => omega_0 = 1/sqrt(L*C)
L = 0.05
C = 2.2e-6
f0 = 1. / (2. * np.pi * np.sqrt(L * C))
print(f"Erwartete Resonanzfrequenz: f0 = {f0:.2f} Hz")
```

Der Eintrag $Z_L$ in Zeile 4, Spalte 3 stammt aus Gleichung (4), der
Maschenregel für die mittlere Masche: Der Strom $i_3$ fließt durch die
Spule, daher steht $Z_L \cdot i_3$ als Spannungsabfall in dieser Masche.
````

## Amplituden- und Phasengang als Frequenzgang

Wir berechnen jetzt die Übertragungsfunktion für ein dichtes Frequenzraster
und erhalten den vollständigen Frequenzgang des Filters.

```{code-cell} python
# Frequenzraster: 1 bis 10000 Hz mit 1000 Punkten
freq_arr = np.linspace(1., 10000., 1000)

# Übertragungsfunktion für alle Frequenzen
antwort_arr = np.array([getUebertragung(f) for f in freq_arr])
ampl_arr  = antwort_arr[:, 0]   # Amplitudengang
phase_arr = antwort_arr[:, 1]   # Phasengang

# Maximale Verstärkung und Mittenfrequenz
idx_max  = np.argmax(ampl_arr)
f_mitte  = freq_arr[idx_max]
ampl_max = ampl_arr[idx_max]

print(f"Maximaler Amplitudengang: {ampl_max:.4f}  bei f = {f_mitte:.1f} Hz")
```

```{code-cell} python
import matplotlib.pyplot as plt

fig, ax = plt.subplots(nrows=2, ncols=2, figsize=(12, 8))

# Oben links: Amplitudengang, lineare Achsen
ax[0][0].plot(freq_arr, ampl_arr, color='tab:blue')
ax[0][0].axvline(f_mitte, color='tab:red', linestyle='--',
                 label=f'Mittenfrequenz {f_mitte:.0f} Hz')
ax[0][0].set_xlabel('f in Hz')
ax[0][0].set_ylabel('|H(f)|')
ax[0][0].set_title('Amplitudengang (lineare Achsen)')

ax[0][0].grid(True)

# Oben rechts: Phasengang, lineare Achsen

ax[0][1].set_xlabel('f in Hz')
ax[0][1].set_ylabel(r'$\varphi$ in °')
ax[0][1].set_title('Phasengang (lineare Achsen)')
ax[0][1].grid(True)

# Unten links: Amplitudengang, doppelt-logarithmische Achsen (Bode-Diagramm)
ax[1][0].loglog(freq_arr, ampl_arr, color='tab:blue')
ax[1][0].axvline(f_mitte, color='tab:red', linestyle='--')
ax[1][0].set_xlabel('f in Hz')
ax[1][0].set_ylabel('|H(f)|')
ax[1][0].set_title('Amplitudengang (doppelt-logarithmisch)')
ax[1][0].grid(True, which='both')

# Unten rechts: Phasengang, logarithmische Frequenzachse
ax[1][1].semilogx(freq_arr, phase_arr, color='tab:blue')
ax[1][1].axvline(f_mitte, color='tab:red', linestyle='--')
ax[1][1].set_xlabel('f in Hz')
ax[1][1].set_ylabel(r'$\varphi$ in °')
ax[1][1].set_title('Phasengang (logarithmische Frequenzachse)')
ax[1][1].grid(True, which='both')

plt.tight_layout()
plt.show()
```

Die logarithmische Darstellung (Bode-Diagramm, untere Zeile) ist in der
Filtertechnik Standard, weil sie den nutzbaren Frequenzbereich und die
Flankensteilheit außerhalb des Durchlassbandes besser sichtbar macht.

````{admonition} Lösung
import numpy as np

# Frage 1: Vergleich analytisch vs. numerisch
L = 0.05
C = 2.2e-6
f0_analytisch = 1. / (2. * np.pi * np.sqrt(L * C))
print(f"Analytisch:  f0     = {f0_analytisch:.2f} Hz")
print(f"Numerisch:   f_mitte = {f_mitte:.2f} Hz")

# Frage 2: -3 dB-Grenzfrequenzen
schwellenwert = ampl_max / np.sqrt(2.)
print(f"\nSchwellenwert (-3 dB): {schwellenwert:.4f}")

# Indizes, wo ampl_arr >= Schwellenwert
maske = ampl_arr >= schwellenwert
indizes = np.argwhere(maske)
f_grenz_unten = freq_arr[indizes[0][0]]
f_grenz_oben  = freq_arr[indizes[-1][0]]
bandbreite    = f_grenz_oben - f_grenz_unten

print(f"Untere Grenzfrequenz: {f_grenz_unten:.1f} Hz")
print(f"Obere Grenzfrequenz:  {f_grenz_oben:.1f} Hz")
print(f"Bandbreite:           {bandbreite:.1f} Hz")

Ausgabe (näherungsweise):
```
Analytisch:  f0      = 480.72 Hz
Numerisch:   f_mitte = 481.68 Hz
Schwellenwert (-3 dB): 0.1017
Untere Grenzfrequenz: ...
Obere Grenzfrequenz:  ...
```

Zu Frage 3: Auf logarithmischen Achsen wird die Frequenzachse gestaucht. Ein
Potenzgesetz $|H| \propto f^n$ erscheint auf doppelt-logarithmischen Achsen
als Gerade mit der Steigung $n$. Die Flanken eines Filters folgen
näherungsweise einem solchen Potenzgesetz, daher die geraden Linien.
````

## Zusammenfassung und Ausblick

Das RLC-Bandpassfilter führt auf ein komplexes $5 \times 5$-LGS. Die
Übertragungsfunktion $H = u_1/U_0$ fasst Amplituden- und Phasengang in
einer einzigen komplexen Zahl zusammen. Für den vollständigen Frequenzgang
rufen wir `np.linalg.solve` in einer Schleife über alle Frequenzen auf. Die
Darstellung als Bode-Diagramm mit logarithmischen Achsen ist in der
Filtertechnik Standard.

In der nächsten Einheit verlassen wir die Elektrotechnik und wenden LGS auf
ein Thema aus der Strukturmechanik an: die **statische Analyse ebener
Fachwerke**. Das Prinzip ist dasselbe, die Koeffizienten kommen jetzt aus
der Festigkeitslehre.
