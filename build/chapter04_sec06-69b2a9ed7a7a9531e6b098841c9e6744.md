````{admonition} Übung 4.1 (✩)
:class: tip
Gegeben ist folgender Python-Code für einen einfachen RC-Tiefpassfilter mit
zwei Maschen. Lesen Sie den Code, ohne ihn auszuführen.

```python
import numpy as np

R  = 1000.
C  = 1.e-6
U0 = 5.

omega = 2. * np.pi * 100.
ZC    = 1. / (1j * omega * C)

A = np.array([
    [R + ZC,    -ZC  ],
    [-ZC,    ZC + ZC  ],
], dtype=complex)

b = np.array([U0, 0.], dtype=complex)

x = np.linalg.solve(A, b)
```

1. Wie viele Maschen hat das Netzwerk, und welche physikalischen Größen
   sind die Unbekannten in `x`?
2. Was gibt `np.abs(x[0])` zurück: den Betrag des Eingangsstroms oder den
   Ausgangsstroms? Begründen Sie anhand der Matrixstruktur.
3. Warum ist `A` komplex, obwohl `R` reell ist? Was bewirkt der Term `ZC`
   auf der Diagonale?
4. Führen Sie den Code aus und bestätigen Sie Ihre Antworten.

````{admonition} Lösung
:class: tip
:class: dropdown
```python
import numpy as np

R  = 1000.
C  = 1.e-6
U0 = 5.
omega = 2. * np.pi * 100.
ZC    = 1. / (1j * omega * C)

A = np.array([
    [R + ZC,    -ZC  ],
    [-ZC,    ZC + ZC  ],
], dtype=complex)
b = np.array([U0, 0.], dtype=complex)

x  = np.linalg.solve(A, b)
I1, I2 = x

print(f"|I1| = {np.abs(I1):.6f} A  (Eingangsstrom)")
print(f"|I2| = {np.abs(I2):.6f} A  (Strom durch zweiten Kondensator)")
print(f"Phase I1: {np.angle(I1, deg=True):.2f}°")
```

Das Netzwerk hat 2 Maschen; die Unbekannten `x[0]` und `x[1]` sind die
Maschenströme $I_1$ und $I_2$. `np.abs(x[0])` ist der Betrag des
Eingangsstroms $I_1$. Die Matrix ist komplex, weil $Z_C = 1/(j\omega C)$
imaginär ist; selbst der reelle Widerstand $R$ erscheint in einer Zeile
neben $Z_C$, was die gesamte Zeile komplex macht.

Betrachten Sie die Steifigkeitsmatrix `KTruss` eines Fachwerks mit drei Knoten

1. `KTruss` hat die Dimension $6 \times 6$. Der Block
   `KTruss[0:2, 4:6]` verknüpft die Freiheitsgrade von Knoten 0 mit
   denen von Knoten 2. Was bedeutet es physikalisch, wenn dieser Block
   ausschließlich Nullen enthält?
2. `KTruss` ist immer symmetrisch. Warum muss das so sein (eine Satz,
   physikalisches Argument)?
3. Wir setzen alle Einträge der ersten Zeile und ersten Spalte von `KTruss`
   auf null. Was passiert, wenn wir danach `np.linalg.solve` aufrufen?
   Testen Sie es.

````{admonition} Lösung
:class: tip
:class: dropdown
```python
import numpy as np

# Frage 1: KTruss[0:2, 4:6] = 0 bedeutet, dass kein Stab Knoten 0 direkt
# mit Knoten 2 verbindet. Eine Kraft an Knoten 2 erzeugt keine direkte
# Steifigkeit am Knoten 0 (nur indirekt über Knoten 1).

# Frage 2: KTruss ist symmetrisch, weil die Arbeit, die eine Kraft an
# Knoten i durch eine Verschiebung an Knoten j leistet, gleich ist wie
# umgekehrt (Maxwell'sches Reziprozitätstheorem). Physikalisch: Aktion
# und Reaktion sind gleich.

# Frage 3: erste Zeile/Spalte null -> singuläre Matrix -> Fehler
E  = 2.1e11
d  = 1.e-2
A  = np.pi * 0.25 * d**2
NodePos = np.array([[0., 1., 2.], [0., 1., 0.]])
numNodes = 3
FixedNodeIndices = [0, 2]
C = np.array([[0,1,0],[1,0,1],[0,1,0]], dtype=float)

KTruss = np.zeros((6, 6))
for i in range(numNodes):
    for j in range(i+1, numNodes):
        if C[i,j]:
            diff   = NodePos[:,j] - NodePos[:,i]
            l      = np.linalg.norm(diff)
            phi    = np.arctan2(diff[1], diff[0])
            k      = E * A / l
            cp, sp = np.cos(phi), np.sin(phi)
            Kij    = k * np.array([[cp**2, sp*cp],[sp*cp, sp**2]])
            KTruss[2*i:2*(i+1), 2*i:2*(i+1)] += Kij
            KTruss[2*j:2*(j+1), 2*j:2*(j+1)] += Kij
            KTruss[2*i:2*(i+1), 2*j:2*(j+1)] -= Kij
            KTruss[2*j:2*(j+1), 2*i:2*(i+1)] -= Kij

K_defekt = KTruss.copy()
K_defekt[0, :] = 0.
K_defekt[:, 0] = 0.

try:
    np.linalg.solve(K_defekt, np.ones(6))
except np.linalg.LinAlgError as e:
    print(f"Fehler: {e}")
```

Wenn `KTruss[0:2, 4:6]` null ist, gibt es zwischen Knoten 0 und Knoten 2
keine direkte mechanische Kopplung. Nullzeilen/Nullspalten machen die Matrix
singulär: `np.linalg.solve` wirft dann einen `LinAlgError`.

Analysieren Sie das RLC-Netzwerk aus Kapitel 4.1 mit veränderten Bauteilen:

| Parameter | Wert |

1. Berechnen Sie die analytische Resonanzfrequenz

   $\omega \in [1, 2000]$ rad/s und bestimmen Sie die numerische

3. Vergleichen Sie den maximalen Laststrom $|I_3|_\text{max}$ mit dem

   Was sagt das über das Filterverhalten des Schwingkreises aus?

````{admonition} Lösung
:class: tip
:class: dropdown
```python
import numpy as np
import matplotlib.pyplot as plt

C1 = 100.e-6
C2 = 100.e-6
L  = 20.e-3
R1 = 5.
RL = 200.
U0 = 150.

# Frage 1
f0 = 1. / (2. * np.pi * np.sqrt(L * C1))
print(f"Analytische Resonanzfrequenz: f0 = {f0:.2f} Hz  "
      f"(omega_0 = {2*np.pi*f0:.2f} rad/s)")

# Frage 2
def getLaststrom(omega):
    ZL  = 1j * omega * L
    ZC1 = 1. / (1j * omega * C1)
    ZC2 = 1. / (1j * omega * C2)
    A   = np.array([
        [ZC1,    R1 + ZL,         0.  ],
        [0.,  -(R1 + ZL),    ZC2 + RL ],
        [1.,       -1.,         -1.   ],
    ], dtype=complex)
    b   = np.array([U0, 0., 0.], dtype=complex)
    return np.linalg.solve(A, b)[2]

omega_arr = np.arange(1, 2001, 1)
I3_arr    = np.abs(np.array([getLaststrom(w) for w in omega_arr]))
idx_res   = np.argmax(I3_arr)

print(f"Numerische Resonanzfrequenz: f_res = {omega_arr[idx_res]/(2*np.pi):.2f} Hz")
print(f"\n|I3|_max (Resonanz):    {I3_arr[idx_res]:.4f} A")
print(f"|I3| bei omega=1 rad/s: {I3_arr[0]:.6f} A")
print(f"|I3| bei omega=2000:    {I3_arr[-1]:.6f} A")
```

Der Laststrom ist weit von der Resonanzfrequenz entfernt sehr klein:
Der Schwingkreis wirkt als Bandpassfilter für den Laststrom, er lässt
nur Frequenzen in der Nähe von $f_0$ effizient durch den Lastwiderstand fließen.

```python
import numpy as np

E = 2.1e11
d = 1.e-2
A = np.pi * 0.25 * d**2

NodePos = np.array([[0., 1., 2., 0., 1.],
                    [0., 0., 0., 1., 1.]])
numNodes        = 5
FixedNodeIndices = [0, 3]

extForcesOnNodes = np.zeros((numNodes, 2))
extForcesOnNodes[2, 1] = -3000.
FTruss = extForcesOnNodes.flatten()

FreeNodeIndices = [ni for ni in range(numNodes) if ni not in FixedNodeIndices]
reduceMask = []
for ni in FreeNodeIndices:
    reduceMask += [2*ni, 2*ni+1]
reduceMask = np.array(reduceMask)


def loeseFachwerk(C):
    KTruss = np.zeros((2*numNodes, 2*numNodes))
    for i in range(numNodes):
        for j in range(i+1, numNodes):
            if C[i, j]:
                diff   = NodePos[:, j] - NodePos[:, i]
                l      = np.linalg.norm(diff)
                phi    = np.arctan2(diff[1], diff[0])
                k      = E * A / l
                cp, sp = np.cos(phi), np.sin(phi)
                Kij    = k * np.array([[cp**2, sp*cp],[sp*cp, sp**2]])
                KTruss[2*i:2*(i+1), 2*i:2*(i+1)] += Kij
                KTruss[2*j:2*(j+1), 2*j:2*(j+1)] += Kij
                KTruss[2*i:2*(i+1), 2*j:2*(j+1)] -= Kij
                KTruss[2*j:2*(j+1), 2*i:2*(i+1)] -= Kij
    Ured   = np.linalg.solve(KTruss[reduceMask,:][:,reduceMask], FTruss[reduceMask])
    UTruss = np.zeros(2*numNodes)
    UTruss[reduceMask] = Ured
    return UTruss


# Original
C0 = np.zeros((numNodes, numNodes))
C0[0,1]=C0[1,2]=C0[1,3]=C0[1,4]=C0[2,4]=C0[3,4]=1
C0 = C0 + C0.T
u0 = loeseFachwerk(C0)

# Mit Stab 0-4
C1 = C0.copy(); C1[0,4]=C1[4,0]=1
u1 = loeseFachwerk(C1)

# Mit Stab 2-3
C2 = C0.copy(); C2[2,3]=C2[3,2]=1
u2 = loeseFachwerk(C2)

print(f"{'Variante':<20} {'Absenkung Knoten 2 in mm':>25}")
print("-" * 48)
print(f"{'Original':<20} {abs(u0[5])*1e3:>25.4f}")
print(f"{'+ Stab 0-4':<20} {abs(u1[5])*1e3:>25.4f}")
print(f"{'+ Stab 2-3':<20} {abs(u2[5])*1e3:>25.4f}")
```

Der Stab 0-4 verbindet das linke Lager direkt mit dem oberen rechten
Knoten und aktiviert einen zusätzlichen Kraftpfad, der die Last effizienter
ableitet. Stab 2-3 verbindet den Lastknoten mit dem rechten Lager horizontal,
was ebenfalls steifend wirkt, aber je nach Geometrie weniger wirkungsvoll.

```python
import numpy as np
import matplotlib.pyplot as plt

# --- Parameter ---
E   = 2.1e11
d   = 1.e-2
rho = 7800.
g   = 9.81
a   = 1.0
h   = 0.7
A   = np.pi * 0.25 * d**2
n   = 20

# --- Teil 1: Knotenkoordinaten ---
NodePos = np.zeros((2, n))
for i in range(n):
    if i % 2 == 0 and i != 0:
        NodePos[1, i] = h
        NodePos[0, i] = i * a / 2
    else:
        NodePos[0, i] = (i + 1) * a / 2
NodePos[0, 0] = 0.
numNodes        = n
FixedNodeIndices = [0, n - 1]

# Konnektivitätsmatrix
C = np.zeros((n, n))
for i in range(n - 3):
    if i % 2 == 0:
        C[i, [i+1, i+2]] = 1
    else:
        C[i, [i+1, i+2, i+3]] = 1
C[n-3, [n-2, n-1]] = 1
C[n-2, n-1] = 1
C = C + C.T
print(f"Anzahl Stäbe: {int(C.sum()/2)}")

# --- Teil 2: Eigengewicht ---
extForcesOnNodes = np.zeros((n, 2))
for i in range(n):
    for j in range(i+1, n):
        if C[i, j]:
            l = np.linalg.norm(NodePos[:, j] - NodePos[:, i])
            wt = rho * A * l * g
            extForcesOnNodes[i, 1] -= wt / 2.
            extForcesOnNodes[j, 1] -= wt / 2.

FTruss = extForcesOnNodes.flatten()
print(f"Gesamtgewicht 20-Knoten-Brücke: {abs(FTruss[1::2].sum()):.2f} N")

# --- Teil 3: Steifigkeitsmatrix und Lösung ---
KTruss = np.zeros((2*n, 2*n))
for i in range(n):
    for j in range(i+1, n):
        if C[i, j]:
            diff   = NodePos[:, j] - NodePos[:, i]
            l      = np.linalg.norm(diff)
            phi    = np.arctan2(diff[1], diff[0])
            k      = E * A / l
            cp, sp = np.cos(phi), np.sin(phi)
            Kij    = k * np.array([[cp**2, sp*cp],[sp*cp, sp**2]])
            KTruss[2*i:2*(i+1), 2*i:2*(i+1)] += Kij
            KTruss[2*j:2*(j+1), 2*j:2*(j+1)] += Kij
            KTruss[2*i:2*(i+1), 2*j:2*(j+1)] -= Kij
            KTruss[2*j:2*(j+1), 2*i:2*(i+1)] -= Kij

FreeNodeIndices = [ni for ni in range(n) if ni not in FixedNodeIndices]
reduceMask = []
for ni in FreeNodeIndices:
    reduceMask += [2*ni, 2*ni+1]
reduceMask = np.array(reduceMask)

Ured   = np.linalg.solve(KTruss[reduceMask,:][:,reduceMask], FTruss[reduceMask])
UTruss = np.zeros(2*n)
UTruss[reduceMask] = Ured

uy = UTruss[1::2]
idx_max = np.argmin(uy)
print(f"Maximale Absenkung: Knoten {idx_max}, uy = {uy[idx_max]*1e3:.4f} mm")

# Nutzlast hinzufügen
