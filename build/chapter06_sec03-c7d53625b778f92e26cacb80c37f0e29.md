# 6.3 Fahrt entlang einer Bahn

In Kapitel 6.2 hat der Sicherheitsscanner eine Kiste im Schutzfeld entdeckt,
und das FTF hat angehalten. Die **Leitsteuerung**, also der Rechner, der alle
Fahrzeuge der Halle koordiniert, hat die Kiste inzwischen in die Hallenkarte
eingetragen. Sie schickt dem FTF eine **Ausweichbahn**: eine Folge von
Punkten, die zwischen Kiste und Säule hindurch zur Übergabestation führt. Die
Bahnpunkte sagen dem FTF, wo es hinfahren soll, aber nicht, wohin es dabei
zeigen muss. *Wie bestimmen wir aus den Bahnpunkten den Gierwinkel?*

Bisher haben wir die Pose des FTF immer vorgegeben. In diesem Kapitel
berechnen wir den Gierwinkel aus der Bahn. Dafür lernen wir eine Variante des
Arkustangens kennen, die jede Fahrtrichtung richtig erkennt. Dann bestimmen wir
den Gierwinkel an jedem Bahnpunkt und zeichnen das FTF entlang der ganzen Bahn.
So prüfen wir, ob es an der Kiste und an der Säule vorbeikommt.

## In welche Richtung muss das FTF fahren?

Die Ausweichbahn besteht aus neun Bahnpunkten im Abstand von etwa einem halben
Meter. Der erste Bahnpunkt ist die Fahrzeugmitte bei $(4, 2)$, der letzte die
Übergabestation bei $(8, 2.5)$. Das FTF fährt von Punkt zu Punkt und soll
dabei immer zum nächsten Bahnpunkt zeigen.

Zuerst führen wir zwei Zellen aus. Die erste enthält die vorgegebene
Zeichenfunktion aus Kapitel 6.1. Ihren Parameter `bahn` nutzen wir jetzt zum
ersten Mal: Er zeichnet Bahnpunkte als gestrichelte Linie. Die zweite Zelle
enthält die Importe, die Funktionen `transformationsmatrix` und `transformiere`
aus Kapitel 5.3 sowie Umriss, Pose und Übergabestation aus Kapitel 6.1. Die
Hallenkarte enthält jetzt zusätzlich die Kiste. Dazu kommen die Bahnpunkte als
Array mit einer Zeile pro Punkt.

```{code-cell} python
# Vorgegebene Zeichenfunktion: einfach ausführen, sie muss nicht verstanden werden.
def zeichne_halle(fahrzeuge=None, koordinatensysteme=None, messpunkte=None,
                  scanner=None, schutzfeld=None, ziele=None, bahn=None,
                  umgebung=None, beschriftungen=None, titel='',
                  bereich=(0, 10, 0, 8)):
    """Zeichnet einen Ausschnitt der Halle von oben.

    fahrzeuge: Ecken eines Fahrzeugumrisses als Array, Zeile = [x, y], die
               ersten beiden Ecken bilden die Vorderkante, oder eine Liste
               solcher Arrays für mehrere Fahrzeuge (optional)
    koordinatensysteme: homogene 3x3-Matrix eines Koordinatensystems oder eine
               Liste solcher Matrizen, gezeichnet werden die x-Achse (rot) und
               die y-Achse (blau) mit 0.8 m Länge (optional)
    messpunkte: Messpunkte als Array, Zeile = [x, y], werden als rote Punkte
                gezeichnet (optional)
    scanner: Lage [x, y] des Scanners, zeichnet die Laserstrahlen vom Scanner

                gefüllt und gestrichelt umrandet (optional)
    ziele: Zielpunkte als Array, Zeile = [x, y], werden als Kreuze markiert (optional)
    bahn: Bahnpunkte als Array, Zeile = [x, y], werden als gestrichelte Linie
          mit Punkten über den Fahrzeugen gezeichnet (optional)
    umgebung: Ecken von Flächen wie Regalen oder Paletten als Array oder Liste
              von Arrays, werden grau gefüllt (optional)
    beschriftungen: Legendentexte, einer pro Fahrzeug, ohne Beschriftungen
                    werden alle Fahrzeuge blau umrandet (optional)
    titel: Diagrammtitel
    bereich: sichtbarer Ausschnitt (x_min, x_max, y_min, y_max) in m

    farben = [blau, rot, orange, grau]
    if isinstance(fahrzeuge, np.ndarray):
        fahrzeuge = [fahrzeuge]
    if isinstance(koordinatensysteme, np.ndarray):
        koordinatensysteme = [koordinatensysteme]
    if isinstance(umgebung, np.ndarray):
        umgebung = [umgebung]
    fig, ax = plt.subplots(figsize=(7, 6))

    # Umgebung: Regale, Paletten, Säulen
    if umgebung is not None:
        for flaeche in umgebung:
            ax.fill(flaeche[:, 0], flaeche[:, 1], facecolor='#DDDEDE',
                    edgecolor=grau, linewidth=1, zorder=0)

    # Schutzfeld gelb gefüllt, gestrichelt umrandet

        ax.fill(schutzfeld[:, 0], schutzfeld[:, 1], facecolor='#FFEC7F',

                label='Schutzfeld', zorder=1)

    # Bahn als gestrichelte Linie mit Punkten, über den Fahrzeugen
    if bahn is not None:

                marker='o', markersize=3, label='Bahn', zorder=4)

    # Fahrzeuge: Umriss hellblau gefüllt, Vorderkante (Ecke 0 bis Ecke 1) orange
    if fahrzeuge is not None:

            ecken = fahrzeuge[k]

            ax.fill(ecken[:, 0], ecken[:, 1], facecolor='#CCDEE9', edgecolor=farbe,

    # Messpunkte als rote Punkte, auf Wunsch mit Laserstrahlen vom Scanner aus
    if messpunkte is not None:

    ax.set_aspect('equal')
```

```{code-cell} python
import numpy as np
import matplotlib.pyplot as plt

# Funktionen aus Kapitel 5.3
def transformationsmatrix(winkel, tx, ty):
    """Homogene Matrix: um winkel (Radiant) drehen, dann um (tx, ty) verschieben."""
    return np.array([
        [np.cos(winkel), -np.sin(winkel), tx],
        [np.sin(winkel),  np.cos(winkel), ty],
        [0.0,             0.0,            1.0],
    ])

def transformiere(T, punkte):
    """Wendet die homogene Matrix T auf alle Punkte an, Zeile = [x, y]."""
    punkte_hom = np.ones((len(punkte), 3))
    punkte_hom[:, 0:2] = punkte
    ergebnis = (T @ punkte_hom.T).T
    return ergebnis[:, 0:2]

# Ecken des FTF im Fahrzeugkoordinatensystem in m, Zeile = [x, y]
umriss = np.array([
    [ 0.6, -0.4],   # vorne rechts
    [ 0.6,  0.4],   # vorne links
    [-0.6,  0.4],   # hinten links
    [-0.6, -0.4],   # hinten rechts
])

# Hallenkarte: Regal, Palette, Säule und die Kiste aus Kapitel 6.2
# in Hallenkoordinaten in m
regal = np.array([[0.5, 6.5], [9.5, 6.5], [9.5, 7.5], [0.5, 7.5]])
palette = np.array([[5.6, 4.0], [6.8, 4.0], [6.8, 4.8], [5.6, 4.8]])
saeule = np.array([[6.3, 0.3], [6.7, 0.3], [6.7, 0.7], [6.3, 0.7]])
kiste = np.array([[5.67, 2.14], [5.97, 2.66], [5.63, 2.86], [5.33, 2.34]])
halle = [regal, palette, saeule, kiste]

# Pose des FTF wie in Kapitel 6.2: Mitte bei (4, 2) m, Gierwinkel 30 Grad
T_WF = transformationsmatrix(np.deg2rad(30), 4, 2)
umriss_W = transformiere(T_WF, umriss)

# Übergabestation aus Kapitel 6.1 in Hallenkoordinaten in m
station = np.array([[8.0, 2.5]])

# Ausweichbahn der Leitsteuerung: Bahnpunkte in Hallenkoordinaten in m,
# Zeile = [x, y]
bahn = np.array([
    [4.0, 2.0 ],   # Start: Fahrzeugmitte
    [4.5, 1.72],
    [5.0, 1.55],
    [5.5, 1.47],
    [6.0, 1.45],
    [6.5, 1.69],
    [7.0, 2.17],
    [7.5, 2.5 ],
    [8.0, 2.5 ],   # Ziel: Übergabestation
])

zeichne_halle(umriss_W, koordinatensysteme=T_WF, bahn=bahn, ziele=station,
              umgebung=halle, titel='Ausgangslage: Ausweichbahn zur Station')
```

Das FTF zeigt noch mit $30°$ auf die Kiste. Bevor es losfährt, muss es sich
zur Bahn ausrichten. Die Richtung zum nächsten Bahnpunkt ist der
Differenzvektor `bahn[1] - bahn[0]` mit den Komponenten $\Delta x$ und
$\Delta y$. Für seinen Winkel $\psi$ gegen die $x_W$-Achse gilt

$$\tan\psi = \frac{\Delta y}{\Delta x}.$$

Naheliegend ist also der **Arkustangens**, die Umkehrfunktion des Tangens.
NumPy berechnet ihn mit `np.arctan`, das Ergebnis ist in Radiant. Mit
`np.rad2deg`, dem Gegenstück zu `np.deg2rad`, rechnen wir es in Grad um. Wir
probieren das für den ersten Abschnitt der Bahn aus und gleich auch für die
spätere Rückfahrt von der Station zum Startpunkt.

```{code-cell} python
# Richtung vom ersten zum zweiten Bahnpunkt
richtung = bahn[1] - bahn[0]
psi_hin = np.arctan(richtung[1] / richtung[0])
print('Richtungsvektor zum nächsten Bahnpunkt in m:', richtung)
print(f'Gierwinkel mit np.arctan: {np.rad2deg(psi_hin):.1f}°')

# Rückfahrt: vom letzten Bahnpunkt (Station) zurück zum ersten (Start)
richtung_zurueck = bahn[0] - bahn[-1]
psi_zurueck = np.arctan(richtung_zurueck[1] / richtung_zurueck[0])
print('Richtungsvektor für die Rückfahrt in m:', richtung_zurueck)
print(f'Gierwinkel mit np.arctan: {np.rad2deg(psi_zurueck):.1f}°')
```

Für den ersten Abschnitt erhalten wir $-29.2°$. Die Bahn führt also nach
rechts unten, das passt zum Bild. Für die Rückfahrt erhalten wir $7.1°$. Das
kann nicht stimmen: Die Rückfahrt führt nach links, das FTF müsste also
ungefähr in negative $x_W$-Richtung zeigen. Ein Gierwinkel von $7.1°$ zeigt
dagegen nach rechts, genau vom Startpunkt weg. *Warum irrt sich der
Arkustangens?*

```{admonition} Aus der Mathematik: Arkustangens und Quadranten
:class: note
Der Arkustangens liefert nur Winkel zwischen $-90°$ und $90°$, also Richtungen
mit $\Delta x > 0$. Für die Richtungen $(4, 0.5)$ und $(-4, -0.5)$ ist der
Quotient $\Delta y / \Delta x$ gleich $0.125$, der Arkustangens kann die
beiden nicht unterscheiden. Bei $\Delta x = 0$ ist der Quotient nicht einmal
definiert. Die Funktion **arctan2** nimmt deshalb $\Delta y$ und $\Delta x$
einzeln entgegen. An ihren Vorzeichen erkennt sie, in welchem Quadranten die
Richtung liegt, und liefert Winkel von $-180°$ bis $180°$.
```

NumPy stellt diese Funktion als `np.arctan2(dy, dx)` bereit. Dabei steht wie
im Quotienten $\Delta y / \Delta x$ die $y$-Komponente zuerst. Anschließend
richten wir das FTF auf die Bahn aus: Es behält seine Mitte bei $(4, 2)$ und
bekommt den neuen Gierwinkel.

```{code-cell} python
# Gierwinkel mit np.arctan2(dy, dx): zuerst die y-, dann die x-Komponente
psi_start = np.arctan2(richtung[1], richtung[0])
psi_zurueck = np.arctan2(richtung_zurueck[1], richtung_zurueck[0])
print(f'Gierwinkel zum nächsten Bahnpunkt: {np.rad2deg(psi_start):.1f}°')
print(f'Gierwinkel für die Rückfahrt: {np.rad2deg(psi_zurueck):.1f}°')

# Das FTF steht mit 30 Grad da und dreht sich auf der Stelle zur Bahn
drehung_grad = np.rad2deg(psi_start) - 30
print(f'Drehung auf der Stelle: {drehung_grad:.1f}°')

T_WF_start = transformationsmatrix(psi_start, 4, 2)
zeichne_halle(transformiere(T_WF_start, umriss), koordinatensysteme=T_WF_start,
              bahn=bahn, ziele=station, umgebung=halle,
              titel='FTF auf die Bahn ausgerichtet')
```

Für den ersten Abschnitt ändert sich nichts, denn dort ist $\Delta x > 0$. Für
die Rückfahrt liefert `np.arctan2` jetzt $-172.9°$. Das sind genau $180°$
weniger als die $7.1°$ des Arkustangens, also die entgegengesetzte Richtung.
Um auf die Bahn zu kommen, dreht sich das FTF um $-59.2°$. Das Minuszeichen
bedeutet wie in Kapitel 5.1 eine Drehung im Uhrzeigersinn, also nach rechts.
Unser FTF hat einen **Differentialantrieb**: Seine beiden Antriebsräder links
und rechts werden einzeln angetrieben. Drehen sie gegenläufig, dreht sich das
FTF auf der Stelle, sofern Fahrwerk und Last das zulassen. FTF mit anderen
Fahrwerken können das nicht unbedingt. Im Bild zeigt die $x_F$-Achse jetzt
genau auf den zweiten Bahnpunkt.

## Wie dreht sich das FTF entlang der Bahn?

Was für den ersten Abschnitt funktioniert, wiederholen wir jetzt für alle
Abschnitte. Das FTF steht an Bahnpunkt `k` und soll zum Bahnpunkt `k + 1`
zeigen. Neun Bahnpunkte haben acht Abschnitte. Die Schleife läuft deshalb mit
`range(len(bahn) - 1)` nur bis zum vorletzten Punkt. Die Gierwinkel sammeln wir
in einem Array, das wir wie die Messpunkte in Kapitel 6.1 vorher mit
`np.zeros` anlegen, und füllen es in der Schleife Eintrag für Eintrag. Der
letzte Bahnpunkt hat keinen Nachfolger. Dort behält das FTF die Richtung des
letzten Abschnitts bei, wir übernehmen also den vorletzten Winkel. Zum Schluss
zeichnen wir die Gierwinkel über der Nummer des Bahnpunkts.

```{code-cell} python
# Gierwinkel an jedem Bahnpunkt: Richtung zum nächsten Bahnpunkt
psi = np.zeros(len(bahn))
for k in range(len(bahn) - 1):
    richtung = bahn[k + 1] - bahn[k]
    psi[k] = np.arctan2(richtung[1], richtung[0])

# Der letzte Bahnpunkt hat keinen Nachfolger und behält die letzte Richtung
psi[-1] = psi[-2]

psi_grad = np.rad2deg(psi)
print('Gierwinkel in Grad:', np.round(psi_grad, 1))

fig, ax = plt.subplots(figsize=(7, 4))
ax.plot(range(len(bahn)), psi_grad, marker='o')
ax.set_xlabel('Bahnpunkt k')
ax.set_ylabel('Gierwinkel in Grad')
ax.set_title('Gierwinkel entlang der Ausweichbahn')
ax.grid(True)
plt.show()
```

Das FTF startet mit $-29.2°$ nach rechts unten und steht an der Station mit
$0°$ parallel zur Hallenwand. Dazwischen dreht es sich erst nach links und
zuletzt wieder nach rechts. Am stärksten ändert sich der Gierwinkel dort, wo
die Bahn am stärksten gekrümmt ist.

Unsere Rechnung hat eine Eigenheit. `psi[k]` ist die Richtung der Strecke von
Bahnpunkt `k` zu Bahnpunkt `k + 1`. Eine Strecke durch zwei Punkte einer Kurve
heißt **Sekante**. Die Richtung der Bahn in einem Punkt selbst gibt dagegen die
**Tangente** an. Am tiefsten Bahnpunkt `k = 4` sehen wir den Unterschied
deutlich: Dort verläuft die Bahn ungefähr waagerecht, das FTF zeigt aber schon
mit $25.6°$ zum nächsten Punkt hinauf. Je dichter die Bahnpunkte liegen, desto
besser passt die Sekante zur Tangente. Die Steigung $\Delta y / \Delta x$ der
Sekante heißt **Differenzenquotient**. In Kapitel 7.1 nähern wir mit ihm
Ableitungen an und untersuchen, wie genau diese Näherung ist.

````{admonition} Lösung
Die Schleife füllt nur die Einträge `psi[0]` bis `psi[7]`, einen pro
Abschnitt. Den letzten Eintrag `psi[8]` setzt die Zeile `psi[-1] = psi[-2]`
nach der Schleife. Ohne sie bliebe er auf dem Startwert $0$ aus `np.zeros`.
Bei unserer Bahn wäre das zufällig richtig, bei einer anderen Bahn aber nicht.
Die größte Linksdrehung beträgt $27.9°$ von Bahnpunkt 3 zu 4. Dort hat das FTF
den tiefsten Punkt erreicht und fährt wieder hinauf. Die größte Rechtsdrehung
beträgt $-33.4°$ von Bahnpunkt 6 zu 7, dort richtet sich das FTF für die
Station parallel zur Wand aus. Mit doppelt so vielen Bahnpunkten verteilt sich
jede dieser Drehungen auf mehr und kleinere Schritte, ungefähr halb so große.
Die Sekanten werden kürzer und passen besser zur Tangente. Das FTF fährt also
ruhiger und zeigt an jedem Bahnpunkt genauer in die Richtung der Bahn.

Die einfache Differenz zweier Gierwinkel funktioniert hier, weil unsere Bahn
nie in negative $x_W$-Richtung führt. Dort springt `np.arctan2` von $180°$ auf
$-180°$, und die Differenz kann um $360°$ falsch sein. Aufgabe 6.4 in Kapitel
6.5 zeigt, wie es dazu kommt und wie wir den Wert korrigieren.
````

## Kommt das FTF an der Kiste vorbei?

Mit `bahn[k]` und `psi[k]` kennen wir an jedem Bahnpunkt die ganze Pose des
FTF. Wie in Kapitel 6.1 bauen wir daraus mit `transformationsmatrix` die Matrix
$\mathbf{T}_{WF}$ auf und rechnen den Umriss mit `transformiere` in
Hallenkoordinaten um, jetzt für jeden Bahnpunkt einzeln. Die Umrisse sammeln
wir in einer Liste. Dafür legen wir vor der Schleife eine leere Liste an, und
in der Schleife hängt `append` jeden neuen Umriss hinten an, wie die Abstände in
Teil 3 von Kapitel 6.2. `zeichne_halle` zeichnet dann alle Umrisse der Liste
übereinander. Mit dem Parameter `bereich` zeigen wir wie in Teil 1 von Kapitel
6.2 nur einen Ausschnitt der Halle, hier den Bereich um die Bahn.

```{code-cell} python
# Leere Liste für die Umrisse an allen Bahnpunkten
fahrzeuge = []
for k in range(len(bahn)):
    # Pose am Bahnpunkt k: Lage aus der Bahn, Gierwinkel aus psi
    T_WF_k = transformationsmatrix(psi[k], bahn[k, 0], bahn[k, 1])
    # Umriss in Hallenkoordinaten umrechnen und hinten an die Liste anhängen
    fahrzeuge.append(transformiere(T_WF_k, umriss))

print('Anzahl der Umrisse:', len(fahrzeuge))
print('Ecken am tiefsten Bahnpunkt in m:')
print(np.round(fahrzeuge[4], 3))

zeichne_halle(fahrzeuge, bahn=bahn, ziele=station, umgebung=halle,
              titel='Fahrt entlang der Ausweichbahn', bereich=(3, 9, 0, 4))
```

Jeder Umriss ist ein Schnappschuss des FTF an einem Bahnpunkt. Zusammen zeigen
sie ungefähr die Fläche, die das FTF auf seiner Fahrt überstreicht. Die orange
Vorderkante zeigt an jedem Bahnpunkt in Richtung des nächsten Punkts. An zwei
Stellen wird es eng: an der Kiste bei den Bahnpunkten 2 und 3 und an der Säule
bei Bahnpunkt 5. Das FTF berührt keines der beiden Hindernisse, die Lücken sind
aber nur wenige Dezimeter breit.

Das Bild hat zwei Grenzen. Es zeigt das FTF nur an den Bahnpunkten. Dazwischen
dreht sich ein echtes FTF allmählich, in unserem Modell springt es dagegen von
einem Gierwinkel zum nächsten. Außerdem lesen wir die Lücken nur ab. Bevor die
Leitsteuerung eine Bahn freigibt, muss sie die Abstände nachrechnen. Wie das
geht, sehen wir im Projekt in Kapitel 6.4.

## Zusammenfassung und Ausblick

Aus zwei Bahnpunkten berechnen wir den Gierwinkel mit `np.arctan2(dy, dx)`.
Anders als der Arkustangens `np.arctan` erkennt diese Funktion an den
Vorzeichen von $\Delta x$ und $\Delta y$, in welchem Quadranten die Richtung
liegt, und liefert Winkel von $-180°$ bis $180°$. In einer Schleife über alle
Abschnitte erhalten wir den Gierwinkel an jedem Bahnpunkt. Dabei nähern wir
die Richtung der Bahn durch die Richtung der Sekante zum nächsten Bahnpunkt an.
Mit Lage und Gierwinkel kennen wir an jedem Bahnpunkt die Pose. Daraus bauen
wir $\mathbf{T}_{WF}$ auf, rechnen den Umriss in die Halle um und sammeln die
Umrisse in einer Liste. Die Schnappschüsse zeigen, wo es auf der Fahrt eng
wird.

Im Projekt in Kapitel 6.4 biegt das FTF in einen Regalgang ein, auf einer Bahn
aus zwei Geraden und einem Viertelkreis. Gierwinkel und Umrisse bestimmen wir
dort wie in diesem Kapitel. Wie nah das FTF einer Regalecke kommt, lesen wir
dann nicht mehr nur ab, sondern rechnen es mit der inversen Matrix aus Kapitel
6.1 nach. Den Differenzenquotienten $\Delta y / \Delta x$, der in jeder Sekante
steckt, untersuchen wir in Kapitel 7.1 genauer.
