# 9.3 Simpson-Regel und scipy.integrate.quad

In Abschnitt 9.1 haben wir die Trapezregel kennengelernt: lineare
Interpolation zwischen Messpunkten, Fehlerordnung $O(\Delta t^2)$. *Geht es
noch genauer?* Ja, wenn wir statt einer Geraden eine Parabel durch je drei
aufeinanderfolgende Punkte legen. Das ist die Idee der Simpson-Regel.

Außerdem kennen wir manchmal nicht nur diskrete Messwerte, sondern das
analytische Modell selbst. Für solche Fälle bietet SciPy mit
`scipy.integrate.quad` ein professionelles Werkzeug, das die Genauigkeit
automatisch kontrolliert. Am Ende von Abschnitt 9.3 haben wir damit den
Bremsweg sowohl aus Sensordaten als auch aus dem analytischen Modell
berechnet und können beide Ergebnisse direkt vergleichen.

## Die Simpson-Regel: Parabolapproximation statt Geraden

Die Trapezregel verbindet je zwei benachbarte Messpunkte durch eine Gerade.
Die **Simpson-Regel** legt stattdessen eine Parabel durch je drei
aufeinanderfolgende Punkte $(t_i, v_i)$, $(t_{i+1}, v_{i+1})$,
$(t_{i+2}, v_{i+2})$ und integriert diese analytisch. Das Ergebnis für
ein Doppelintervall $[t_i, t_{i+2}]$ lautet:

$$\Delta s_i = \frac{\Delta t}{3}\bigl(v_i + 4\,v_{i+1} + v_{i+2}\bigr).$$

Der mittlere Punkt geht mit dem vierfachen Gewicht ein. Summiert man über
alle Doppelintervalle, erhält man die zusammengesetzte Simpson-Regel:

$$s \approx \frac{\Delta t}{3}\bigl(v_0 + 4v_1 + 2v_2 + 4v_3 + \cdots
  + 2v_{n-3} + 4v_{n-2} + v_{n-1}\bigr).$$

Weil immer drei Punkte ein Doppelintervall bilden, muss die Anzahl der
Intervalle gerade sein, also $n$ (Anzahl Punkte) ungerade.

```{code-cell} python
import numpy as np
import matplotlib.pyplot as plt
import matplotlib.style as style
style.use('seaborn-v0_8')

# --- Bremsdaten aus Abschnitt 9.2 (gleicher Seed ergibt identische Werte) ---
np.random.seed(12)

v0_bremsung = 100 / 3.6   # Anfangsgeschwindigkeit in m/s
k_bremsung  = 0.35        # Abklingkonstante in 1/s
T_bremsung  = 8.0         # Messdauer in s
dt_sensor   = 0.5         # Abtastrate in s

t_mess  = np.arange(0, T_bremsung + dt_sensor, dt_sensor)
v_exakt = v0_bremsung * np.exp(-k_bremsung * t_mess)
v_mess  = np.maximum(v_exakt + np.random.normal(0, 0.3, size=len(t_mess)), 0.0)

# np.arange mit 0.5-Schritten von 0 bis 8 ergibt 17 Punkte (n ungerade: gut für Simpson)
print(f"Anzahl Messpunkte: {len(t_mess)}  (ungerade: {len(t_mess) % 2 == 1})")
```

```{code-cell} python
import numpy as np

def simpson(t, v):
    """Zusammengesetzte Simpson-Regel für gleichmäßiges Raster.

    Parameters
    ----------
    t : np.ndarray
        Zeitpunkte, gleichmäßiger Abstand, ungerade Anzahl erforderlich.
    v : np.ndarray
        Funktionswerte an den Zeitpunkten.

    Returns
    -------
    float
        Näherungswert des Integrals.
    """
    n  = len(v)
    dt = t[1] - t[0]

    # Simpson erfordert ungerade Punktanzahl (gerade Anzahl von Intervallen)
    if n % 2 == 0:
        raise ValueError(f"Simpson-Regel erfordert ungerade Punktanzahl, erhalten: {n}")

    # Gewichtsvektor: 1, 4, 2, 4, 2, ..., 4, 1
    # Randpunkte: Gewicht 1; innere Punkte abwechselnd 4 und 2
    gewichte = np.ones(n)
    gewichte[1:-1:2] = 4   # ungerade Indizes: Gewicht 4
    gewichte[2:-2:2] = 2   # gerade Indizes (außer Rändern): Gewicht 2

    return (dt / 3) * np.dot(gewichte, v)

# --- Vergleich auf den Bremsdaten ---
bremsweg_trapez  = np.trapezoid(v_mess, t_mess)
bremsweg_simpson = simpson(t_mess, v_mess)

# Analytischer Referenzwert
bremsweg_exakt = (v0_bremsung / k_bremsung) * (1 - np.exp(-k_bremsung * T_bremsung))

print(f"Exakter Bremsweg: {bremsweg_exakt:.4f} m")
print()
print(f"Trapezregel:      {bremsweg_trapez:.4f} m  "
      f"(Fehler: {bremsweg_trapez - bremsweg_exakt:+.4f} m)")
print(f"Simpson-Regel:    {bremsweg_simpson:.4f} m  "
      f"(Fehler: {bremsweg_simpson - bremsweg_exakt:+.4f} m)")
```

Beide Methoden liefern hier sehr ähnliche Ergebnisse, weil der dominante
Fehler aus dem Messrauschen stammt, nicht aus der Integrationsmethode. Wie
viel genauer Simpson bei glatten Funktionen tatsächlich ist, sehen wir im
nächsten Unterabschnitt.

## Fehlerordnung $O(\Delta t^4)$ und Methodenwahl

Die Trapezregel hat Fehlerordnung $O(\Delta t^2)$: halbiert man $\Delta t$,
sinkt der Fehler auf ein Viertel. Die Simpson-Regel erreicht $O(\Delta t^4)$:
halbiert man $\Delta t$, sinkt der Fehler auf ein Sechzehntel. Dieser
Unterschied ist im Log-Log-Plot direkt als unterschiedliche Steigung
sichtbar.

```{code-cell} python
import numpy as np
import matplotlib.pyplot as plt
import matplotlib.style as style
style.use('seaborn-v0_8')

# --- Testfunktion: analytisches Bremsmodell (kein Rauschen) ---
v0_test = 100 / 3.6    # Anfangsgeschwindigkeit in m/s
k_test  = 0.35         # Abklingkonstante in 1/s
T_test  = 8.0          # Integrationsgrenzen in s

# Exaktes Integral als Referenz
integral_exakt = (v0_test / k_test) * (1 - np.exp(-k_test * T_test))

# Verschiedene Auflösungen: n = 3, 5, 7, ..., 201 (immer ungerade für Simpson)
n_werte = np.arange(3, 202, 2)

fehler_trapez  = []
fehler_simpson = []

for n in n_werte:
    t = np.linspace(0, T_test, n)
    v = v0_test * np.exp(-k_test * t)   # rauschfreie Testfunktion

    fehler_trapez.append(abs(np.trapezoid(v, t) - integral_exakt))
    fehler_simpson.append(abs(simpson(t, v)     - integral_exakt))

dt_werte = T_test / (n_werte - 1)   # Schrittweite zu jeder Punktanzahl

# --- Log-Log-Plot: Fehler über Schrittweite ---
fig, ax = plt.subplots(figsize=(7, 5))

ax.loglog(dt_werte, fehler_trapez,  color='#005A94', linewidth=2,
          label='Trapezregel  $O(\\Delta t^2)$')
ax.loglog(dt_werte, fehler_simpson, color='#E60000', linewidth=2,
          label='Simpson-Regel  $O(\\Delta t^4)$')

# Referenzlinien zur Orientierung
dt_ref = np.array([dt_werte[0], dt_werte[-1]])
ax.loglog(dt_ref, 2e-3 * (dt_ref / dt_ref[0])**2,
          color='#005A94', linewidth=1, linestyle=':', alpha=0.6)
ax.loglog(dt_ref, 2e-5 * (dt_ref / dt_ref[0])**4,
          color='#E60000', linewidth=1, linestyle=':', alpha=0.6)

ax.set_xlabel('Schrittweite $\\Delta t$ in s')
ax.set_ylabel('Absoluter Fehler in m')
ax.set_title('Fehlerordnung: Trapezregel vs. Simpson-Regel')
ax.legend()
ax.grid(True, which='both')
plt.tight_layout()
plt.show()

# --- Zahlenwerte zum Ablesen ---
idx = len(n_werte) // 2   # mittlere Auflösung als Beispiel
print(f"Bei n = {n_werte[idx]} Punkten (dt = {dt_werte[idx]:.3f} s):")
print(f"  Trapezregel:   Fehler = {fehler_trapez[idx]:.2e} m")
print(f"  Simpson-Regel: Fehler = {fehler_simpson[idx]:.2e} m")
print(f"  Simpson ist {fehler_trapez[idx] / fehler_simpson[idx]:.0f}-mal genauer")
```

Der Log-Log-Plot zeigt zwei parallele Geraden mit unterschiedlicher
Steigung: die blaue Gerade hat Steigung 2 (Trapezregel), die rote hat
Steigung 4 (Simpson). Bei gleicher Schrittweite ist Simpson um mehrere
Größenordnungen genauer.

*Wann sollte man dann trotzdem die Trapezregel wählen?* Bei verrauschten
Sensordaten bringt Simpson keinen Vorteil: der dominante Fehler kommt nicht
aus der Integrationsmethode, sondern aus dem Rauschen. Die Faustregel lautet:
Simpson für glatte analytische Funktionen, Trapezregel für verrauschte
Messdaten.

## scipy.integrate.quad für analytische Bremsmodelle

Wenn das analytische Modell bekannt ist, muss man es nicht erst auf einem
Gitter auswerten. `scipy.integrate.quad` integriert eine Python-Funktion
direkt und schätzt dabei automatisch die Genauigkeit ab.

```{code-cell} python
from scipy.integrate import quad
import numpy as np

# --- Analytisches Bremsmodell als Python-Funktion ---
v0_modell = 100 / 3.6   # Anfangsgeschwindigkeit in m/s
k_modell  = 0.35        # Abklingkonstante in 1/s

def v_brems(t):
    """Analytisches Bremsmodell: v(t) = v0 * exp(-k*t)."""
    return v0_modell * np.exp(-k_modell * t)

# --- scipy.integrate.quad: Funktion, untere Grenze, obere Grenze ---
# Rückgabe: (Integralwert, geschätzter absoluter Fehler)
bremsweg_quad, fehlerabschaetzung = quad(v_brems, 0, 8.0)

# Analytische Referenz
bremsweg_exakt = (v0_modell / k_modell) * (1 - np.exp(-k_modell * 8.0))

print(f"scipy.integrate.quad:  {bremsweg_quad:.6f} m")
print(f"Analytisch exakt:      {bremsweg_exakt:.6f} m")
print(f"Fehlerabschätzung:     {fehlerabschaetzung:.2e} m")
print(f"Tatsächlicher Fehler:  {abs(bremsweg_quad - bremsweg_exakt):.2e} m")
```

`quad` gibt zwei Werte zurück: den Integralwert und eine Schätzung des
absoluten Fehlers. Die Fehlerabschätzung liegt hier im Bereich der
Maschinengenauigkeit, weil die Funktion glatt und gut konditioniert ist.

Der Unterschied zur Trapezregel: `np.trapezoid` braucht ein Array von
Funktionswerten auf einem festen Gitter. `quad` nimmt die Funktion selbst
und wählt intern adaptiv, wo es sie auswertet. Das ist effizienter für
glatte Funktionen, aber nicht anwendbar, wenn nur Messdaten vorliegen.

```{code-cell} python
from scipy.integrate import quad
import numpy as np
import numpy as np

# --- Einordnung: wann quad, wann Trapezregel? ---
# Faustregel in einer Übersicht:

print("Methode          | Eingabe          | Anwendungsfall")
print("-" * 60)
print("np.trapezoid     | Messdaten y[i]   | Sensordaten, diskrete Messung")
print("simpson()        | Messdaten y[i]   | Glatte Daten, n ungerade")
print("quad(f, a, b)    | Funktion f(t)    | Analytisches Modell bekannt")
```

```python
from scipy.integrate import quad
import numpy as np

# --- Teilaufgabe 1: uneigentliches Integral e^{-t} ---
# Analytisch: Stammfunktion -e^{-t}, ausgewertet 0 bis inf ergibt 0 - (-1) = 1
ergebnis_1, fehler_1 = quad(lambda t: np.exp(-t), 0, np.inf)
print(f"Integral e^(-t) von 0 bis inf: {ergebnis_1:.6f}  (Fehler: {fehler_1:.2e})")

# --- Teilaufgabe 2: Bremsweg bis zum vollständigen Stillstand ---
v0_modell = 100 / 3.6
k_modell  = 0.35

ergebnis_2, fehler_2 = quad(lambda t: v0_modell * np.exp(-k_modell * t),
                             0, np.inf)
# Analytisch: v0/k = (100/3.6) / 0.35
bremsweg_inf_exakt = v0_modell / k_modell

print(f"Bremsweg bis Stillstand:       {ergebnis_2:.4f} m")
print(f"Analytisch (v0/k):             {bremsweg_inf_exakt:.4f} m")
print(f"Bremsweg bis T=8 s:            {(v0_modell/k_modell)*(1-np.exp(-k_modell*8)):.4f} m")
```

Erwartete Ausgabe:
```
Integral e^(-t) von 0 bis inf: 1.000000  (Fehler: 5.84e-11)
Bremsweg bis Stillstand:       79.3651 m
Analytisch (v0/k):             79.3651 m
Bremsweg bis T=8 s:            74.5397 m
```

Das Integral bis Unendlich ist der theoretische Bremsweg, wenn das Fahrzeug
nie vollständig zum Stillstand kommt (exponentieller Abfall). Er beträgt
$v_0 / k \approx 79{,}4$ m. Der Bremsweg bis $T = 8$ s ist mit rund
$74{,}5$ m bereits 94 % davon, weil $v(8) \approx 2{,}6$ m/s schon sehr
klein ist.

## Zusammenfassung und Ausblick

Die Simpson-Regel erreicht durch quadratische Interpolation die
Fehlerordnung $O(\Delta t^4)$, was sie bei glatten Funktionen der
Trapezregel $O(\Delta t^2)$ weit überlegen macht. Bei verrauschten
Messdaten dominiert dagegen das Messrauschen, und die einfachere
Trapezregel genügt. `scipy.integrate.quad` integriert eine analytisch
gegebene Funktion adaptiv und ist das Werkzeug der Wahl, wenn das Modell
bekannt ist.

In Abschnitt 9.4 wenden wir alle drei Methoden auf ein neues
ingenieurtechnisches Problem an: die geleistete Arbeit entlang einer
nichtlinearen Federkennlinie.
