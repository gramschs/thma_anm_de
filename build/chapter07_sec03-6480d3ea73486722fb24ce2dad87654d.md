```{code-cell} python
import numpy as np
import matplotlib.pyplot as plt

# Funktion aus Kapitel 7.1
def ableitung(werte, dt):
    """Ableitung einer Messreihe mit Schrittweite dt.

    Innen zentraler Differenzenquotient, am ersten Punkt vorwärts,
    am letzten Punkt rückwärts.
    """
    n = len(werte)
    ergebnis = np.zeros(n)
    ergebnis[0] = (werte[1] - werte[0]) / dt
    ergebnis[-1] = (werte[-1] - werte[-2]) / dt
    for k in range(1, n - 1):
        ergebnis[k] = (werte[k + 1] - werte[k - 1]) / (2 * dt)
    return ergebnis

# Funktionen aus Kapitel 7.2
def fahrprofil(t):
    """Strecke in m bei der sanften Anfahrt, t in s von 0 bis 2."""
    return 0.4 * (t - 2 / np.pi * np.sin(np.pi * t / 2))

def geschwindigkeit(t):
    """Exakte Geschwindigkeit in m/s, die Ableitung von fahrprofil."""
    return 0.4 * (1 - np.cos(np.pi * t / 2))
```

````{admonition} Lösung
:class: tip
:class: dropdown
```python
def rueckwaerts(funktion, t, dt):
    """Rückwärtsdifferenzenquotient von funktion an der Stelle t."""
    return (funktion(t) - funktion(t - dt)) / dt

t_0 = 1.5
exakt = geschwindigkeit(t_0)
for dt in [0.1, 0.05, 0.025]:
    abweichung = rueckwaerts(fahrprofil, t_0, dt) - exakt
    print(f'dt = {dt:5}: Abweichung {abweichung:+.5f} m/s')
```
Ausgabe:

```text
dt =   0.1: Abweichung -0.02333 m/s
dt =  0.05: Abweichung -0.01139 m/s
dt = 0.025: Abweichung -0.00563 m/s
```

Die Taylor-Entwicklung lautet

$$s(t - \Delta t) = s(t) - \Delta t \cdot s'(t) + \frac{\Delta t^2}{2}
\cdot s''(t) - \ldots$$

Eingesetzt in den Rückwärtsdifferenzenquotienten ergibt sich

$$\frac{s(t) - s(t - \Delta t)}{\Delta t} = s'(t) - \frac{\Delta t}{2}
\cdot s''(t) + \ldots$$

Der größte Fehlerterm ist $-\frac{\Delta t}{2} \cdot s''(t)$. Er hat denselben
Betrag wie beim Vorwärtsdifferenzenquotienten, aber das umgekehrte Vorzeichen.
Mit $s''(1.5) = 0.444\,\text{m/s}^2$ sagt er die Abweichungen $-0.0222$,
$-0.0111$ und $-0.0056\,\text{m/s}$ voraus. Die berechneten Werte liegen etwas
darüber, weil der nächste Term der Taylor-Entwicklung bei großer Schrittweite
noch mitspielt. Halbiert sich die Schrittweite, halbiert sich auch die
Abweichung, die Fehlerordnung ist also 1. Das negative Vorzeichen passt zu
Kapitel 7.1: Der Rückwärtsdifferenzenquotient mittelt über die Zeit vor
$t = 1.5\,\text{s}$, als das FTF noch langsamer war.
````

````{admonition} Aufgabe 7.4 (✩✩)
dt = 0.1
t = np.linspace(0, 1.5, 16)
````

````{admonition} Lösung
a = ableitung(v, dt)
a_min = np.min(a)
print(f'Größte Verzögerung: {-a_min:.2f} m/s²')
if -a_min > 0.2 * 9.81:

# Abschlussfrage: Bremsweg bei gleichbleibender Verzögerung

ax[0].plot(t, v, marker='o')
ax[0].set_ylabel('Geschwindigkeit in m/s')
ax[1].plot(t, a, marker='o')

ax[1].legend()
for einzelachse in ax:
````
