# 5.1 Drehmatrizen in 2D und 3D

```{admonition} Lernziele
:class: attention
* [ ] Sie können die 2D-Drehmatrix $\mathbf{R}(\varphi)$ aus einem Drehwinkel aufbauen und auf einen Punkt anwenden.
* [ ] Sie wissen, was eine **orthogonale Matrix** ist, und können die Eigenschaft $\mathbf{R}^\top \mathbf{R} = \mathbf{I}$ numerisch überprüfen.
* [ ] Sie können die drei Grunddrehmatrizen $\mathbf{R}_x$, $\mathbf{R}_y$, $\mathbf{R}_z$ für Drehungen im 3D-Raum aufbauen.
* [ ] Sie wissen, was **Euler-Winkel** sind, und können eine Gesamtrotation als Verkettung von Grunddrehungen berechnen.
```
