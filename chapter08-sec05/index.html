import numpy as np

T_mess = np.array([100,  72,  53,  40,  31,  25])
T_0   = 100.0
T_inf =  20.0

def modell(t, lam):
    return T_inf + (T_0 - T_inf) * np.exp(-lam * t)

def kosten(lam):
    return np.mean((T_mess - modell(t_mess, lam))**2)

def ableitung_kosten(lam, dx=1e-6):
    return (kosten(lam + dx) - kosten(lam - dx)) / (2 * dx)

lam_aktuell = 0.01
alpha = 0.01

# Korrigierte Zeile A: Minus statt Plus
for i in range(8):
    grad = ableitung_kosten(lam_aktuell)
    lam_aktuell = lam_aktuell - alpha * grad
    print(f"i={i+1}: lam = {lam_aktuell:.5f},  K = {kosten(lam_aktuell):.2f}")

Zu Frage 1: Ja, Zeile A enthält einen Fehler. Der Update-Schritt lautet lam_aktuell + alpha * grad statt lam_aktuell - alpha * grad. Das Minus ist entscheidend: GD bewegt sich entgegen dem Gradienten, also bergab. Mit einem Plus bewegt sich der Algorithmus mit dem Gradienten, also bergauf.

Zu Frage 2: Bei lam = 0.01 liegt das Minimum rechts (bei ca. 0.05). Die Kostenfunktion fällt nach rechts, also ist K′(0.01)<0K'(0.01) < 0K′(0.01)<0 (grad ist negativ).

Zu Frage 3: Mit dem falschen Plus-Zeichen und negativem grad wird lam_aktuell kleiner (bewegt sich nach links, weg vom Minimum). Der Kostenwert K nimmt zu.

# Code-Zelle
Lösung
import numpy as np
import matplotlib.pyplot as plt
import matplotlib.style as style
style.use('seaborn-v0_8')
from scipy.optimize import minimize

np.random.seed(11)

A_wahr     = 10.0
delta_wahr =  0.5
omega_wahr =  5.0

t_mess = np.linspace(0, 4, 50)
x_wahr = A_wahr * np.exp(-delta_wahr * t_mess) * np.cos(omega_wahr * t_mess)
x_mess = x_wahr + np.random.normal(0, 0.5, len(t_mess))

# --- Frage 1: Plot der Messdaten ---
fig, ax = plt.subplots()
ax.plot(t_mess, x_mess, 'o', markersize=3, label='Messwerte')
ax.axhline(0, color='gray', linewidth=0.8)
ax.set_xlabel('Zeit in s')
ax.set_ylabel('Auslenkung x in mm')
ax.set_title('Gedämpfte Schwingung (Messdaten)')
ax.legend()
ax.grid(True)
plt.show()

# --- Modell- und Kostenfunktion ---

def modell(t, A, delta, omega):
    """Gedämpfte Schwingung: x(t) = A * exp(-delta*t) * cos(omega*t)."""
    return A * np.exp(-delta * t) * np.cos(omega * t)

def kosten(A, delta, omega):
    """MSE zwischen Modell und Messdaten."""
    return np.mean((x_mess - modell(t_mess, A, delta, omega))**2)

# --- Fragen 2 und 3: Gradient Descent ---
dx = 1e-5

def dK_dA(A, delta, omega):
    return (kosten(A+dx, delta, omega) - kosten(A-dx, delta, omega)) / (2*dx)

def dK_ddelta(A, delta, omega):
    return (kosten(A, delta+dx, omega) - kosten(A, delta-dx, omega)) / (2*dx)

def dK_domega(A, delta, omega):
    return (kosten(A, delta, omega+dx) - kosten(A, delta, omega-dx)) / (2*dx)

def gradient_descent_3d(A_start, delta_start, omega_start,
                         alpha_A=0.01, alpha_delta=0.005, alpha_omega=0.001,
                         n_iter=5000):
    A, delta, omega = A_start, delta_start, omega_start
    for i in range(n_iter):
        A     = A     - alpha_A     * dK_dA(A, delta, omega)
        delta = delta - alpha_delta * dK_ddelta(A, delta, omega)
        omega = omega - alpha_omega * dK_domega(A, delta, omega)
    return A, delta, omega

In der obigen Funktion gradient_descent_3d werden die drei Parameter AAA, δ\deltaδ und ω\omegaω nacheinander aktualisiert. Dabei wird die Ableitung von KKK nach δ\deltaδ und ω\omegaω bereits mit den zuvor aktualisierten Werten von AAA bzw. δ\deltaδ berechnet.

Streng genommen wertet “klassisches” Gradient Descent alle Gradienten am gleichen Punkt (A,δ,ω)(A, \delta, \omega)(A,δ,ω) aus und macht dann einen gemeinsamen Update-Schritt. Die hier verwendete Variante (nacheinander aktualisieren) liefert bei kleinen Lernraten sehr ähnliche Ergebnisse und ist für unsere Zwecke ausreichend. Wichtig ist, dass alle Schritte in Richtung abnehmender Kostenfunktion gehen.

# Guter Startwert

Zu Frage 5: Die Abkühlkurve T(t)=T∞+(T0−T∞)e−λtT(t) = T_\infty + (T_0 - T_\infty) e^{-\lambda t}T(t)=T∞​+(T0​−T∞​)e−λt ist eine monoton fallende Funktion. Für jeden λ\lambdaλ-Wert gibt es genau eine solche Kurve, und die Kostenfunktion hat deshalb nur ein Minimum. Dasselbe gilt für die Wöhlerkurve S=a⋅N−bS = a \cdot N^{-b}S=a⋅N−b.

Bei der gedämpften Schwingung x(t)=Ae−δtcos⁡(ωt)x(t) = A e^{-\delta t} \cos(\omega t)x(t)=Ae−δtcos(ωt) erzeugt der cos⁡(ωt)\cos(\omega t)cos(ωt)-Term ein oszillierendes Muster. Eine Kreisfrequenz ω′=ω+2π/tmax\omega' = \omega + 2\pi / t_\text{max}ω′=ω+2π/tmax​ erzeugt an den Messzeitpunkten eine ähnlich aussehende Kurve wie ω\omegaω, wenn die Abtastdichte nicht ausreicht. Jede dieser Frequenzen entspricht einem lokalen Minimum der Kostenfunktion. GD konvergiert zum nächsten lokalen Minimum, das vom Startwert aus erreichbar ist. scipy verwendet robustere Algorithmen, bleibt aber bei sehr schlechten Startwerten ebenfalls in falschen lokalen Minima stecken.
