Übung 9.3 (✩)

Gegeben ist der folgende Code. Die Funktion simpson entspricht der Implementierung aus Abschnitt 9.3.

import numpy as np
from scipy.integrate import quad

def simpson(t, v):
    n  = len(v)
    dt = t[1] - t[0]
    if n % 2 == 0:
        raise ValueError(
            f"Simpson-Regel erfordert ungerade Punktanzahl, erhalten: {n}"
        )
    gewichte         = np.ones(n)
    gewichte[1:-1:2] = 4
    gewichte[2:-2:2] = 2
    return (dt / 3) * np.dot(gewichte, v)

# Experiment A
t_a = np.linspace(0, 4, 8)
v_a = t_a**2

import numpy as np
from scipy.integrate import quad

def simpson(t, v):
    n  = len(v)
    dt = t[1] - t[0]
    if n % 2 == 0:
        raise ValueError(
            f"Simpson-Regel erfordert ungerade Punktanzahl, erhalten: {n}"
        )
    gewichte         = np.ones(n)
    gewichte[1:-1:2] = 4
    gewichte[2:-2:2] = 2
    return (dt / 3) * np.dot(gewichte, v)

# Experiment A: n=8 gerade -> ValueError
t_a = np.linspace(0, 4, 8)
v_a = t_a**2
try:
    print(f"Experiment A: {simpson(t_a, v_a):.4f}")
except ValueError as e:
    print(f"Experiment A: ValueError: {e}")

# Experiment B: n=9 ungerade -> ok
t_b = np.linspace(0, 4, 9)
v_b = t_b**2
print(f"Experiment B: {simpson(t_b, v_b):.4f}")

# Experiment C
ergebnis_c, fehler_c = quad(lambda x: x**2, 0, 4)
print(f"Experiment C: {ergebnis_c:.4f},  Fehlerabschätzung: {fehler_c:.2e}")

Erwartete Ausgabe:

Experiment A: ValueError: Simpson-Regel erfordert ungerade Punktanzahl, erhalten: 8
Experiment B: 21.3333
Experiment C: 21.3333,  Fehlerabschätzung: 2.37e-13

Zu Frage 1: np.linspace(0, 4, 8) erzeugt 8 Punkte. Die Funktion simpson prüft n % 2 == 0 und wirft einen ValueError, weil 8 gerade ist.

Zu Frage 2: Die Simpson-Regel leitet ihre Formel aus einem Parabolfit ab und ist daher für alle Polynome bis Grad 3 exakt. f(x)=x2f(x) = x^2f(x)=x2 ist ein Polynom zweiten Grades. Simpson macht also keinen Diskretisierungsfehler, unabhängig von der Anzahl der Punkte, solange die Schrittweite konstant ist und die Punktanzahl ungerade (Simpson-Voraussetzung).

Zu Frage 3: quad liefert ebenfalls 21.3333, identisch zum analytischen Wert. Die Fehlerabschätzung 2.37⋅10−132.37 \cdot 10^{-13}2.37⋅10−13 liegt im Bereich der Maschinengenauigkeit und ist kein Zeichen für eine ungenaue Berechnung, sondern für eine sehr gute. Ein Problem wäre eine Fehlerabschätzung, die deutlich größer als die gewünschte Genauigkeit ist, zum Beispiel 10-2 bei einem Ergebnis der Größenordnung 100.

import numpy as np
import matplotlib.pyplot as plt
import matplotlib.style as style
style.use('seaborn-v0_8')
from scipy.integrate import quad

np.random.seed(7)

# --- Eingabe: Federkennlinie ---
k1    = 200.0
k3    = 500.0
x_max = 0.30

x_mess  = np.linspace(0, x_max, 13)
F_exakt = k1 * x_mess + k3 * x_mess**3
F_mess  = F_exakt + np.random.normal(0, 0.4, size=len(x_mess))
F_mess[0] = 0.0

# --- Teilaufgabe 1: Trapezregel auf Messdaten ---
W_trapez = np.trapezoid(F_mess, x_mess)
print(f"Arbeit (Trapezregel): {W_trapez:.4f} J")

# --- Teilaufgabe 2: quad auf analytischem Modell ---
def F_modell(x):
    """Analytisches Federmodell: F(x) = k1*x + k3*x^3."""
    return k1 * x + k3 * x**3

W_quad, fehler_quad = quad(F_modell, 0, x_max)
print(f"Arbeit (quad):        {W_quad:.4f} J  (Fehlerabsch.: {fehler_quad:.2e})")

# --- Teilaufgabe 3: relativer Fehler ---
# Analytisch: Stammfunktion k1*x^2/2 + k3*x^4/4, ausgewertet von 0 bis x_max
W_exakt = k1 * x_max**2 / 2 + k3 * x_max**4 / 4
print(f"Arbeit (exakt):       {W_exakt:.4f} J")
print()
print(f"Rel. Fehler Trapez:   {abs(W_trapez - W_exakt) / W_exakt * 100:.3f} %")
print(f"Rel. Fehler quad:     {abs(W_quad   - W_exakt) / W_exakt * 100:.3f} %")

# --- Teilaufgabe 4: Plot ---
fig, ax = plt.subplots(figsize=(7, 4))
ax.plot(x_mess * 100, F_exakt, color='#005A94', linewidth=2,
        label='Modell $F = k_1 x + k_3 x^3$')
ax.plot(x_mess * 100, F_mess,  color='#E60000', linewidth=1, linestyle='--',
        marker='o', markersize=5, label='Messung')
ax.set_xlabel('Auslenkung $x$ in cm')
ax.set_ylabel('Federkraft $F$ in N')
ax.set_title('Nichtlineare Federkennlinie')
ax.legend()
ax.grid(True)
plt.tight_layout()
plt.show()

Arbeit (exakt):       10.0125 J

Rel. Fehler Trapez:   0.079 %
Rel. Fehler quad:     0.000 %

Die geleistete Arbeit beim Einfedern auf 30 cm beträgt rund 10 J. Der kubische Term trägt dabei etwa k3 xmax4/4≈1.0k_3\,x_\text{max}^4/4 \approx 1.0k3​xmax4​/4≈1.0 J bei, also rund 10 % der Gesamtarbeit.

Zu Frage 5: quad übergibt das analytische Modell direkt an den Integrator, der intern adaptiv auswertet und die Genauigkeit bis zur Maschinengenauigkeit treibt. np.trapezoid kann nur auf den 13 Messpunkten arbeiten und macht daher einen kleinen Diskretisierungsfehler, der zudem das Messrauschen widerspiegelt.
