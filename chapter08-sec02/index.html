Ein Betrieb wäscht Aluminiumteile und trocknet sie danach in einem Ofen bei 100 °C100\,°\text{C}100°C. Anschließend kühlen die Teile auf einem Förderband mit Lüfter in der 20 °C20\,°\text{C}20°C warmen Halle ab. Führen Sie zuerst die folgende Zelle aus. Sie enthält die Funktionen zentral() und gradientenverfahren() aus Kapitel 8.1, die bekannten Temperaturen und die Messdaten.

import numpy as np
import matplotlib.pyplot as plt

# Funktionen aus Kapitel 8.1
def zentral(funktion, stelle, dx):
    """Zentraler Differenzenquotient von funktion an der Stelle stelle."""
    return (funktion(stelle + dx) - funktion(stelle - dx)) / (2 * dx)

def gradientenverfahren(funktion, start, lernrate, toleranz, max_iterationen):
    """Sucht ein Minimum von funktion, Start bei start.

    Gibt alle besuchten Stellen als Array zurück.
    """
    stelle = start
    verlauf = [stelle]
    for k in range(max_iterationen):
        steigung = zentral(funktion, stelle, 1e-6)
        # Abbruchkriterium: Steigung fast null
        if abs(steigung) < toleranz:
            break
        stelle = stelle - lernrate * steigung
        verlauf.append(stelle)
    return np.array(verlauf)

# Bekannte Temperaturen in °C
T_start = 100.0
T_halle = 20.0

# Messzeitpunkte in s und gemessene Temperaturen in °C
t_mess = np.array([0, 5, 10, 15, 20, 25, 30, 35, 40, 45, 50, 55, 60])
T_mess = np.array([100.0, 82.6, 68.2, 56.9, 49.0, 41.9, 37.9, 35.2, 30.3,
                   27.8, 27.1, 25.5, 24.1])

Teil 2: Kostenfunktion aus den Messdaten

Wie gut ein λ\lambdaλ passt, messen wir an den Abweichungen zwischen Messwert und Modell. Wir quadrieren jede Abweichung und bilden den Mittelwert über alle nnn Messungen. Das ergibt die mittlere quadratische Abweichung (englisch mean squared error, kurz MSE):

K(λ)=1n∑i=1n(Tmess,i−T(ti))2.K(\lambda) = \frac{1}{n} \sum_{i=1}^{n} \bigl(T_{\text{mess},i} - T(t_i)\bigr)^2.K(λ)=n1​i=1∑n​(Tmess,i​−T(ti​))2.

Durch das Quadrieren heben sich positive und negative Abweichungen nicht gegenseitig auf, und große Abweichungen zählen stärker als kleine.

Lösung Abschlussfrage

  1. Erstens misst das Thermoelement nicht exakt, jeder Messwert schwankt durch Messrauschen ein wenig nach oben oder unten. Zweitens ist das Abkühlungsgesetz eine Vereinfachung. Es nimmt zum Beispiel an, dass das Teil überall gleich warm ist und der Lüfter gleichmäßig kühlt. Eine glatte Kurve mit einem einzigen freien Parameter kann weder dem Rauschen noch allen Einzelheiten des echten Abkühlvorgangs folgen.

    Die Wurzel aus der mittleren quadratischen Abweichung hat wieder die Einheit °C°\text{C}°C. Hier beträgt sie 0.36 °C2=0.6 °C\sqrt{0.36\,°\text{C}^2} = 0.6\,°\text{C}0.36°C2​=0.6°C. Ein Messwert liegt also typischerweise etwa 0.6 °C0.6\,°\text{C}0.6°C neben der Modellkurve. Für die Auslegung der Kühlstrecke ist das genau genug. Wie viel davon Messrauschen und wie viel Modellfehler ist, verrät der Wert allein nicht. Das zeigen erst die Abweichungen der einzelnen Messwerte von der Kurve. Streuen sie ohne Muster mal nach oben, mal nach unten, überwiegt das Rauschen. Liegen sie über längere Abschnitte auf derselben Seite, beschreibt das Modell den Vorgang nicht genau.
