Zu Frage 1: Zeile A gibt y[0] zurück, das ist die aktuelle Position ϕ\phiϕ. Die korrekte Ableitung der Position ist aber die Geschwindigkeit y[1]. Das vollständige fehlerhafte DGL-System lautet:

y˙1=y1(statt y˙1=y2)\dot{y}_1 = y_1 \quad \text{(statt } \dot{y}_1 = y_2\text{)}y˙​1​=y1​(statt y˙​1​=y2​)
y˙2=−gLsin⁡(y2)(statt y˙2=−gLsin⁡(y1))\dot{y}_2 = -\frac{g}{L}\sin(y_2) \quad \text{(statt } \dot{y}_2 = -\frac{g}{L}\sin(y_1)\text{)}y˙​2​=−Lg​sin(y2​)(statt y˙​2​=−Lg​sin(y1​))

Die erste Gleichung besagt, dass die Position exponentiell wächst (ϕ˙=ϕ\dot{\phi} = \phiϕ˙​=ϕ); die zweite ist eine Pendelgleichung für die Winkelgeschwindigkeit statt für den Winkel.

Zu Frage 2: y[1] ist die Winkelgeschwindigkeit ϕ˙\dot{\phi}ϕ˙​. Zeile B wertet die Rückstellkraft also als sin⁡(ϕ˙)\sin(\dot{\phi})sin(ϕ˙​) aus statt als sin⁡(ϕ)\sin(\phi)sin(ϕ). Für kleine Winkelgeschwindigkeiten gilt sin⁡(ϕ˙)≈ϕ˙\sin(\dot{\phi}) \approx \dot{\phi}sin(ϕ˙​)≈ϕ˙​, was einer seltsamen geschwindigkeitsabhängigen Kraft entspricht, nicht einer positionsabhängigen Rückstellkraft.

Zu Frage 3: Mit ϕ˙(0)=y2(0)=0\dot{\phi}(0) = y_2(0) = 0ϕ˙​(0)=y2​(0)=0 gilt für die zweite Gleichung: y˙2=−(g/L)sin⁡(0)=0\dot{y}_2 = -(g/L)\sin(0) = 0y˙​2​=−(g/L)sin(0)=0. Die Winkelgeschwindigkeit ist ein Gleichgewicht dieser Gleichung und bleibt dauerhaft null (y2(t)≡0y_2(t) \equiv 0y2​(t)≡0). Die erste Gleichung reduziert sich damit auf ϕ˙=ϕ\dot{\phi} = \phiϕ˙​=ϕ, also ϕ(t)=ϕ0 et\phi(t) = \phi_0\,e^tϕ(t)=ϕ0​et. import numpy as np
import matplotlib.pyplot as plt
import matplotlib.style as style
from scipy.integrate import solve_ivp
style.use('seaborn-v0_8')

# --- Parameter ---
L_ind = 0.1        # Induktivität in H
R     = 10.0       # Widerstand in Ohm
C     = 100e-6     # Kapazität in F
U0    = 5.0        # Spannungsamplitude in V

# --- Eigenkreisfrequenz und Dämpfungszahl ---
# Formale Analogie: L_ind <-> m, R <-> c, 1/C <-> k, U0 <-> F0, q <-> x
omega_0_rlc = 1 / np.sqrt(L_ind * C)         # = 316.23 rad/s
D_rlc       = R / (2 * np.sqrt(L_ind / C))   # = 0.1581
c_krit_rlc  = 2 * np.sqrt(L_ind / C)

print(f"omega_0 = {omega_0_rlc:.2f} rad/s")
print(f"D       = {D_rlc:.4f}")

# y[0] = q (Ladung in C), y[1] = q_dot = i (Strom in A)
# L_ind * q_ddot + R * q_dot + q/C = U0 * cos(Omega * t)
# q_ddot = (U0*cos(Omega*t) - R*q_dot - q/C) / L_ind
def f_rlc(t, y, Omega):
    q_dot  = y[1]
    q_ddot = (U0 * np.cos(Omega * t) - R * y[1] - y[0] / C) / L_ind
    return [q_dot, q_ddot]

import numpy as np
import matplotlib.pyplot as plt
import matplotlib.style as style
from scipy.integrate import solve_ivp, cumulative_trapezoid
style.use('seaborn-v0_8')

# --- Parameter ---
m        = 250.0
k_feder  = 16000.0
omega_0  = np.sqrt(k_feder / m)   # = 8.0 rad/s
c_krit   = 2 * np.sqrt(k_feder * m)
A_bahn   = 0.02     # Fahrbahnunebenheit in m
F0_bahn  = k_feder * A_bahn   # = 320 N (effektive Kraftamplitude)
D_werte  = [0.1, 0.3, 1.0]
farben   = ['#005A94', '#E87846', '#E60000']

def f_fahrbahn(t, y, c, Omega):
    # m * x_ddot + c * x_dot + k * x = k * A_bahn * sin(Omega*t)
    x_dot  = y[1]
    x_ddot = (-k_feder * y[0] - c * y[1] + F0_bahn * np.sin(Omega * t)) / m
    return [x_dot, x_ddot]

Für eine Fahrzeugfederung gibt es zwei konkurrierende Anforderungen: Fahrkomfort (kleine stationäre Amplitude bei Resonanz, also größeres DDD) und Handling (schnelles Einschwingen nach einer Einzelstörung wie einer Bodenwelle, was nahe D=1D = 1D=1 liegt). Ein typischer Personenwagen wählt D≈0.25…0.4D \approx 0.25 \ldots 0.4D≈0.25…0.4: Das ist ein Kompromiss, der bei Autobahnfahrten die Resonanzamplitude begrenzt und nach einem Schlagloch das Fahrzeug in wenigen Schwingungen beruhigt. Reine Sportwagen tendieren zu D≈0.5…0.7D \approx 0.5 \ldots 0.7D≈0.5…0.7, um Karosseriebewegungen zu minimieren.
